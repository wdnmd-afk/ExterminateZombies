# 下载的俯视人物素材

本目录保存从互联网下载、许可证已经核实的俯视人物素材。本轮仅完成原始文件归档、解包、许可证记录和图像校验，尚未替换当前玩家显示。

## 素材包

1. `ghostbyte-action-horror-topdown-48x48/`
   - 俯视像素动作恐怖风。
   - 7 张透明 `576 × 48` 精灵条，每张可按 `48 × 48` 切为 12 帧。
   - 包含徒手、手枪、左轮、炸药、钥匙、交互手势和手电筒。
2. `topdown-shooter-animated-64x64/`
   - 俯视像素射击风。
   - 包含手枪、机枪、匕首玩家动画，以及两套额外僵尸动画。
   - 每个 GIF 为 `64 × 64`、4 帧并带透明色。
3. `kenney-topdown-shooter/`
   - CC0 的完整俯视人物备选库。
   - 已提取杀手、普通人物、士兵、幸存者、女性、机器人和僵尸等人物，以及手枪、自动武器和消音武器状态。
   - 画风偏平滑卡通，不属于严格像素风；保留用于完整度优先的备选方案。
