The archive contains a UI strip and three eight-frame minigun animation sets. It was originally sampled directly into the runtime Gatling sprite by `scripts/process_heavy_weapon_assets.ps1`. Since 2026-08-22 the Gatling sprites contain **no pixels from this archive**: the top-down gameplay sprite is drawn by `scripts/process_weapon_topdown_assets.py`, and since 2026-08-23 the side-view icon is generated in-project from a text prompt by `scripts/generate_weapon_assets.mjs`. Neither palette was sampled from this archive either. It is retained only as a shape reference for the barrel cluster. The CC-BY 3.0 attribution obligation continues to apply while the files remain in the repository.
