The archive contains a UI strip and three eight-frame minigun animation sets. It was originally sampled directly into the runtime Gatling sprite by `scripts/process_heavy_weapon_assets.ps1`. Since 2026-08-22 the Gatling sprites are drawn entirely by the project (`scripts/process_heavy_weapon_profiles.py` for the side-view icon, `scripts/process_weapon_topdown_assets.py` for the in-game top-down sprite) and contain **no pixels from this archive**; it is retained as a shape reference for the barrel cluster.
