# 下载的枪械素材

本目录保存从互联网下载、许可证已经核实的原始枪械素材。本轮只完成下载、归档和校验，尚未接入游戏运行时。

## 素材包

1. `pixel-art-guns-128x128/`
   - 统一的 `5 × 5` 透明像素枪械表，单格 `128 × 128`。
   - 包含 MP5、M4A1、AK-47、SPAS-12、Barrett M82、RPG-7、M79 等武器。
2. `486-shotgun-desert-eagle/`
   - 用于补齐沙漠之鹰的透明像素素材，同时包含 486 霰弹枪素材。

两套素材均采用 `CC0 1.0`。完整许可证见同目录的 `LICENSE-CC0-1.0.txt`，具体来源、布局和 SHA-256 见各素材包内的 `SOURCE.md`。

## 使用状态

当前没有把素材映射到 `pistol`、`rifle`、`smg` 等现有武器配置。接入前需要先确认图标用途、世界场景显示尺寸和枪口锚点，避免把 HUD 图标误当作人物持枪动画。
