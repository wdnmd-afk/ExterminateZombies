- Source: https://opengameart.org/content/minigun-user-interface-and-rollcage-barrel
- License: https://creativecommons.org/licenses/by/3.0/
- Runtime derivative: **none.** Since 2026-08-22 no runtime file derives from this archive.

The Gatling side-view icon (`src/assets/processed/weapons/gatling.png`) was first drawn by the
project and, since 2026-08-23, is generated in-project by `scripts/generate_weapon_assets.mjs`
from a text prompt; the top-down sprite is drawn by `scripts/process_weapon_topdown_assets.py`.
Neither contains pixels sampled from this archive, and neither palette was sampled from it.
The archive is retained only as a shape reference for the barrel cluster. The CC-BY 3.0
attribution obligation continues to apply while these files remain in the repository, which is
why this record stays here.

The Flamethrower by TheJosh, the Kenney Topdown Shooter machine gun, and the aron137 Pixel Art Guns sheet are CC0 assets and do not require attribution. Their source records remain in the repository for traceability.
