The downloaded 2048x2048 RGBA texture is retained as the source artifact. It is a 3D model texture atlas, not a usable sprite; the project only took its steel and fuel-tank palette. Since 2026-08-22 the Flamethrower sprites are drawn entirely by the project (`scripts/process_heavy_weapon_profiles.py` and `scripts/process_weapon_topdown_assets.py`) with those palette values written into the spec files, so the sprites contain no pixels from this texture.
