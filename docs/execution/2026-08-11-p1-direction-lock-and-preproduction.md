## 1. 目标

1. 锁定 D-002 单局结构，明确时长、阶段、强化、Boss、失败重开、结算和解锁。

## 3. 已锁定决策

### 3.1 D-002 单局结构

| 项目 | 教学关 | 标准关 / P2 垂直切片 |
| --- | --- | --- |
| 目标时长 | 8-10 分钟 | 10-15 分钟 |
| 进入战斗 | 从点击开始到可控制且首批敌人出现不超过 5 秒 | 同左 |
| 战斗结构 | 3 个战斗阶段 | 3 个常规阶段 + 1 个 Boss 节点 |
| 阶段间隔 | 3-8 秒，只保留补给、播报和一次明确选择 | 同左，不使用空等拖长时长 |
| 强化选择 | 1 次，完成第 2 阶段后保证出现 | 2 次，完成第 1、3 阶段后保证出现 |
| Boss | 不出现 | 仅在配置为 Boss 关时作为独立终局节点出现 |
| 失败 | 保留本关身份；失败页一次点击或按 `R` 重开 | 同左 |
| 重开门槛 | 从死亡到重新进入可操作战斗最多两次操作 | 同左 |
| 结算 | 成败、用时、得分、到达阶段、击杀、伤害、主要资源结果 | 额外显示 Boss 结果、获得解锁和下一关入口 |
| 解锁 | 首次通关解锁下一关；重复通关不重复写入 | 同左 |

补充规则：

1. Boss 不要求每关出现。Boss 是作者化高潮节点，服务于机制教学、章节节奏或主题收束；非 Boss 关可用精英混编或环境事件收尾。
2. 强化频率由关卡阶段保证，普通敌人的随机强化包不再承担“玩家能否体验构筑”的职责。P2 可保留随机包作为额外收益候选，但默认应关闭或设上限，避免单局层数失控。
3. 强化选择冻结战场，选择时间不计入战斗目标时长；P2 记录时同时保留墙钟时长与有效战斗时长。
4. 失败不保存本局武器、弹药、道具和强化；关卡解锁只在通关结算前写入。
5. 无尽模式沿用总纲基线：3 分钟进入明显压力、10 分钟进入高风险、15 分钟后进入极限挑战，本轮不实施其重平衡。

### 3.2 首个正式关卡

**选择第二关“废车站”作为 P2 正式垂直切片，第一关“郊外”保留教学定位。**

选择依据：

1. `tank_boss` 已具备两阶段、震荡、冲锋、场景物连锁、独立动作和恢复窗口，是现有 Boss 中实现与文档基础最完整的一项。
2. 废车、铁轨和狭窄通路能同时验证掩体、拉扯、远程敌人、位移敌人和环境爆炸，不需要把教学关改造成系统堆叠关。
3. 教学关不放 Boss，可把首次体验集中在移动、瞄准、换弹、切枪、场景物和敌人优先级；正式关再验证完整构筑与高潮。
4. P2 只把第二关计为“1 个正式关卡”。第一关在后续按独立教学验收表升级，不占用本轮正式切片名额。

## 4. P2 操作步骤

P2 严格按以下顺序实施；上一阶段达到静态完成标准后才进入下一阶段，最终统一进行完整试玩验收：

1. **正式场景**：确定废车站空间草图、敌人入口、玩家出生、三类战术元素、Boss 区和资源节点；完成地面、边界、障碍、细节、动态与碰撞对应。
2. **核心战斗**：校准玩家移动、四把武器职责、固定武器获取、弹药与换弹窗口、命中和伤害反馈。
3. **敌人与 Boss**：只接入白名单敌群，编排三阶段；完成 `tank_boss` 入场、两阶段、反制窗口、死亡和清场收束。
4. **经济与强化**：用阶段奖励保证两次强化；冻结 12 张卡、武器/弹药/生命/地雷来源，记录资源曲线并移除切片外掉落。
5. **UI 与音频**：完成简报、HUD、阶段/Boss 提示、暂停、失败、结算、解锁；完成四把武器、三类敌人、Boss、环境、UI 与音乐混音。
6. **完整试玩**：从干净存档经主菜单进入，完成失败重开和至少一次完整通关；保存客观证据，再由真人完成手感、难度、画面与听感判断。

## 5. 实施建议

1. 为 P2 建立“切片白名单”配置或校验入口，避免直接删除其余原型内容，也避免它们误入正式关卡。
2. 关卡阶段奖励与普通掉落分开建模；阶段奖励负责节奏确定性，普通掉落负责短期资源波动。
3. 先用现有程序化场景完成空间灰盒验证，再锁定正式位图资产，防止美术完成后才发现通路或预警不可读。
4. 四把武器按职责和失效场景校准，不按统一 DPS 排序；每把都必须有值得切换的敌群或距离窗口。
5. Boss 第二阶段增加决策密度，不依靠单纯加血延长时间；震荡与冲锋必须保留稳定反击窗口。
6. 完整试玩记录使用固定版本、干净存档和明确输入路径；定向注入只证明机制，不替代完整流程。

## 6. 潜在风险

1. **时长风险**：当前第一关基线约 3 分钟通关，目标 8-15 分钟不能靠堆敌人实现，否则会放大重复与疲劳。
2. **随机经济风险**：当前武器与强化均依赖随机掉落，可能导致切片职责无法稳定出现，需要固定节点或保底规则。
3. **内容泄漏风险**：现有关卡波次混入大量非白名单敌人，P2 必须显式限制，而不是默认复用第二关原配置。
4. **职责重叠风险**：MP5 与 M4A1、三种冲刺敌人、三种远程敌人目前存在相似区间，需要以切片代表收敛验证。
5. **场景可读性风险**：狭窄通路、敌方投射、Boss 预警和爆炸链可能互相遮挡，必须先做层级和碰撞对齐检查。
6. **强化放大风险**：现有强化可叠加，保证两次选择后仍需防止组合绕过弹药压力或让 Boss 阶段失效。
7. **验收越界风险**：自动化能证明流程和状态，不能代替真人判断枪感、难度舒适度、视觉统一和混音质量。

## 7. 优化方案

1. 用阶段预算而非敌人总数控制节奏：每阶段记录准备、积压、释放和收束时间。
2. 用固定武器展示节点降低随机方差；正式扩展时再决定保底、掉落权重或关卡预配置方案。
3. 将切片测试指标沉淀为后续五关批次模板，只有通过的系统和内容才进入复用库。
4. P2 通过后再评估 `bomber` 战斗角色、后四把武器和其余 Boss，不因代码已存在而自动纳入正式范围。

## 8. 系统验收标准

### 8.1 玩法与单局流程

1. 从主菜单确认关卡到玩家可控制且首批敌人出现不超过 5 秒。
2. 教学关有效战斗时长落在 8-10 分钟；正式切片落在 10-15 分钟，且各阶段有可辨认的压力变化。
3. 正式切片完整经历三个常规阶段、两次保证强化和一个 Boss 节点，不出现依赖随机掉落才能继续的情况。
4. 死亡后一次点击或按 `R` 即重开；从死亡到重新可操作最多两次操作。
5. 暂停、强化冻结、恢复、失败和通关不会推进或跳过错误的波次计时。

### 8.2 武器

1. 四把武器均可在一次受控完整试玩中获得并实际使用，不依赖调试全武器开关。
2. 每把武器至少有一个明确优势场景和一个明确弱势场景；试玩记录能说明玩家为什么切枪。
3. 弹匣、备用弹药、换弹、拾取和 HUD 数值一致；资源不足能形成压力但不造成稳定软锁。
4. 十二张强化卡只作用于切片四把武器，卡面变化与实际开火、换弹和 HUD 一致。

### 8.3 敌人与 Boss

1. `walker`、`runner`、`lurker`、`tank` 分别建立追击、侧移躲冲刺、掩体躲投射和集中火力四种决策。
2. 所有特殊攻击都有可见前摇、执行、恢复和冷却；预警不只依赖颜色。
3. `tank_boss` 第一阶段至少稳定触发震荡，55% 生命后进入第二阶段并解锁定向冲锋。
4. 玩家可分别通过拉开和侧移规避两种技能，并能识别恢复输出窗口。
5. Boss 震荡触发场景物时只结算一次连锁；死亡动画结束后才通关，死亡期间不移动、不攻击。

### 8.4 关卡与环境

1. 废车站具有可辨认的出生区、主通路、风险死角、补给点、战术热点和 Boss 区。
2. 地面、边界、废车/障碍、非碰撞细节、动态层、入口预警和碰撞层职责清楚且视觉一致。
3. 油桶提供高风险伤害，面粉桶提供可验证的脱身窗口，地雷允许主动布防；三者均至少在完整试玩中产生一次有意义决策。
4. 障碍物外观与碰撞一致，不遮挡玩家、敌人、弹丸、掉落、危险区或 Boss 预警。

### 8.5 UI、结算与解锁

1. HUD 正确显示生命、武器、弹药、道具、阶段、得分、强化状态和 Boss 生命/阶段。
2. 关键战斗提示有稳定优先级，Boss 技能、受伤来源、空弹/换弹和拾取反馈不互相覆盖。
3. 失败页显示结果并提供重开和返回；结算页显示用时、得分、阶段/击杀、Boss 结果、解锁与下一关入口。
4. 首次通关只解锁下一关；失败不解锁；重复通关不产生重复或损坏的存档记录。

### 8.6 美术

1. 玩家、四把武器、四类普通敌人、Boss、地面、障碍、场景物、拾取和特效使用统一像素尺度与最近邻采样。
2. 正式场景不直接并排混用未经调色和比例归一的多作者素材；外部资源来源、许可证和派生步骤进入台账。
3. `1280 x 720`、1x 与 2x 渲染下主体、枪口、碰撞、预警和文字无明显错位或遮挡。
4. 危险、补给、玩家弹、敌方弹和可交互物依靠轮廓、动画或符号共同区分，不只靠颜色。

### 8.7 音频

1. 四把武器的开火、换弹和空弹可辨识；敌人冲刺、远程前摇、Boss 阶段/技能和三类环境元素有对应声音。
2. 菜单、战斗、强化、失败、通关和解锁的音乐/界面事件生命周期正确，无重复循环或场景切换残留。
3. 高频枪声、命中和感染体声音受限频与并发控制，关键 Boss 预警和玩家受伤不会被掩盖。
4. 真人实听确认响度、疲劳度、方向感和关键提示辨识度；自动触发记录不能替代该项。

### 8.8 数值与测试基线

每次完整试玩至少记录：进入战斗耗时、墙钟/有效战斗时长、各阶段耗时、死亡阶段与原因、生命最低值、四把武器首获时间和使用占比、弹药余量、强化选择、环境元素使用、Boss 阶段耗时、重开操作数、最终结算与解锁。

P2 客观通过需要满足：

1. 至少完成一次干净存档失败重开流程和一次不使用跳波、改血、清敌或调试配发的完整通关。
2. 无阻塞级运行时异常、关键资源失败、存档损坏、流程软锁或结算错误。
3. 关键机制具备前、中、后证据；完整流程与定向机制验证分开记录。
4. 类型、自动化、构建和浏览器验证按 `TESTING_RULES.md` 单独申请用户授权，未执行时必须明确标记未验证。
5. V6 真人验收明确判断枪感、节奏、难度、画面和混音；未完成 V6 不得宣称垂直切片最终通过。
