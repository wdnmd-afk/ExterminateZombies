## 实施建议与优化方案

命令回归优先验证当前代码基线，避免继续引用修复前 871 的读数。产物 HTTP 检查与渲染检查分开记录；主包体积只给实测数字和警告，不在验收期间贸然拆包。先收口战役流程与奖励，再测狂潮和反打边界；资源/许可缺口不以验收授权代替用户决策。

## 潜在风险

- 图片代理的本地模拟通过不证明真实供应商可用，也不消耗付费 API。
- 构建通过与静态 HTTP 正常不证明 Canvas 输入、纹理显示或游戏可通关。
- 浏览器执行工具是否提供与测试授权是两件事；授权本身不会生成工具能力。
- 软件渲染或后台节流的帧率不能替代目标设备持续测量。
- 真人手感、难度、混音及外部试玩无法由 Agent 的自动化结果代签。

## 验证方式

命令输出按原文写入 JSON，同时保存开始/结束时间、退出码和执行范围。产物验证记录路径、字节数、SHA-256、HTTP 状态和 MIME；不创建发布或上传行为。最终检查文档差异和证据可解析性；任何未执行项均明确保留。
