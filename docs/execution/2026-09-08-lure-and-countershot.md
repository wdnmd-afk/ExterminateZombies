## 1. 目标

1. 落地推荐的两个玩法：主动组织尸群、射击特殊弹体制造反击。
2. 尸潮调度先在第二关投放，炮弹反打先由爆破者 Boss 提供。
3. 不同时实施其余三个提案，不改首选编队、武器奖励、经济或全局难度。

## 2. 架构与范围

- 场景：主菜单 → 整备 → GameScene/HUDScene → 抽卡或结算；不增加场景。
- 状态：沿用 config 类型、启动校验和 GameScene 管理局内状态；不增加存档字段。
- 输入：新增语义动作 interact，默认 G，接入现有改键与旧存档归一化。
- AI：由 Zombie.seek/updateAbility 驱动；广播只改白名单基础感染体的移动目标。
- 战斗：反打弹单独池化，复用 AreaEffectFactory、damageZombie、Boss 破绽与击杀链。
- 美术：沿用本地图片代理、道具生成/后处理脚本和 PreloadScene，不新增依赖。
- utils、存档、输入、波次、能力、碰撞、暂停、关停、设置及相邻资源管线已预读。

## 3. 锁定的首轮规则

### 尸潮调度

1. 第二关两个固定广播装置，不占携带道具槽，不增加碰撞障碍。
2. 接近后按实际绑定的交互键启动；就地提示次数、倒计时和冷却。
3. 单装置两次使用，每次持续 9 秒，结束后冷却 18 秒；同时只有一个声源有效。
4. 切换装置终止旧广播但不退还次数，避免无限控场。
5. 只吸引 walker、runner、drifter、bloodied、headless；重装、远程和 Boss 免疫。
6. 吸引半径 340px；贴近玩家的感染体仍优先威胁玩家，装置不是无敌安全区。
7. 与现有油桶、穿透武器、地雷组合，不增加默认枪声仇恨或潜行惩罚。

### 炮弹反打

1. 新增 countershot 能力：爆破者基础攻击改为缓慢的实体爆弹。
2. 常规地面轰炸移至后续阶段；震荡与饱和轰炸保留，地面红圈不能击返。
3. 爆弹有独立位图、核心圆环与“击返”标记；实体子弹命中一次即可反打。
4. 消耗命中的一颗子弹，不再触发该子弹的爆炸/碎片/残留，防止重复收益。
5. 返弹朝原发射者当前有效位置直线飞行；发射者死亡或回池后只朝保存的发射位置飞行。
6. 撞敌、撞墙或达到射程只结算一次；直接返弹爆炸不伤玩家，环境连锁仍遵循原有自伤。
7. 爆炸实际覆盖原 Boss 才附加 1.2 秒、1.25 倍受伤的破绽，不无条件打断已预警攻击。
8. 敌弹伤害 30、速度 160、核心半径 14；返弹伤害 260、速度 520、爆炸半径 82。
9. 数值为待试玩初值；反打不是通关必需，无实体子弹的喷射武器不自动反打。

## 5. 实施建议与优化方案

- 沿用 Rules + System 模式，玩法状态不依赖 Phaser。
- 弹体独立池，原发射者用生命周期令牌隔离，避免普通敌弹或复用实体被污染。
- 广播音波低对比、不全屏闪烁；提示使用普惠体，不增加常驻 HUD 面板。
- 爆炸复用可访问性设置及现有特效，不重造粒子系统。
- 先做两张小图，审查轮廓与透明边缘，不把生成母版直接加载到战场。

## 6. 潜在风险分析

| 风险 | 对策 |
| --- | --- |
| 旧存档缺交互键、设置拥挤 | 默认归一化及动态行距，补契约用例 |
| 广播失效后仍被锁定 | 每帧按时间与范围求目标，不在 Zombie 留持久仇恨引用 |
| 暂停消耗冷却/破绽 | 接入 shiftBattleTimers，不新建实时时钟 |
| 多重碰撞重复爆炸 | 先消费状态再回收及伤害，验证重入幂等 |
| 发射者被对象池复用 | 对象身份与生命周期令牌共同核对 |
| 高速子弹掠过核心 | 玩法半径独立于美术，保留足够命中窗口；实景核对低帧率 |
| 广播与障碍/剧本油桶重叠 | 坐标检查及摆位静态复核 |
| Boss 同时叠加攻击过难 | 新基础弹替换而非叠加原基础攻击；地面能力保留预警 |
| 生图失败/不合格 | 不覆盖既有资产，留存候选，不绕过供应商拒绝或无限重试 |

## 7. 验证方式

- 本轮执行：静态代码/字段/调用链/差异检查、素材生成与图片目视检查。
- 本轮不执行：Vitest、类型检查、lint、build、浏览器及 E2E；生图授权不扩展为测试授权。
- 建议申请：新增规则、combat-alerts、config-integrity、level-batch-validation、save-manager、row-grid-layout 定向测试，随后 npm run typecheck，预计 1–3 分钟。
- 广播实景：新存档第二关、G/重绑定、两设备切换、暂停/抽卡、范围与免疫、次数耗尽、重开恢复。
- 返弹实景：发射/躲避/击返、散弹同帧命中、贴身反打、撞墙、射程终止、源 Boss 死亡/回池复用、红圈不可反打、伤害归属。
- 真人验收：是否主动组织清群、是否愿意重复反打；数值与美术满意度不能用静态检查代替。
