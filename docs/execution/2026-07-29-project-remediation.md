# 2026-07-29 项目半成品问题修复

## 目标

将当前“功能入口和配置已存在，但行为、表现、数据契约与验收未闭环”的原型，推进为可验证的首轮完整基线。此次不把配置数量当作完成标准：每项改动必须在玩法、UI、存档与验证链路中闭环。

## 已确认的基线

1. 项目为 Phaser 3 + TypeScript + Vite 的纯前端单机游戏，当前没有后端或路由/API 层。
2. 现有三关和无尽模式可以进入 `GameScene`，但战场仍主要是网格与程序化几何对象。
3. 当前有确定性逻辑缺陷：切枪不会取消已排队的换弹回调；旋转障碍物与 Arcade Physics 碰撞体不一致；HUD 提示没有读取自定义键位。
4. 感染体大多只使用追击和接触攻击，Boss 只依赖数值放大；没有正式音频系统。
5. 存档缺少版本、校验、迁移和重置入口；无尽模式的分离计算与未销毁场景物会累积性能压力。
6. 当前工作区已有用户修改，实施期间不得回退或覆盖这些修改。

## 视觉与交互方向

- **视觉主张**：低照度像素灾区，关卡地面、边界、战术对象和危险预警共同承担空间信息，HUD 只保留战斗决策所需内容。
- **内容布局**：战场先让玩家识别地形、可利用场景物和敌方威胁；HUD 展示真实输入与资源状态；图鉴只描述实际存在的敌人机制。
- **交互原则**：特殊敌人与 Boss 至少有“预警 -> 执行 -> 恢复”三段节奏；远程、冲刺与范围攻击必须存在可见躲避窗口；声音和画面反馈服务命中、危险和场景切换，不制造无关噪声。

## 范围

### 1. 可靠性与数据契约

1. 为换弹建立可取消的定时任务，切枪、场景结束和重开都不能让旧回调修改新局状态。
2. 为旋转障碍物计算与视觉一致的轴对齐包围盒，至少覆盖当前 90 度路障和小角度摆放。
3. 收紧道具、掉落、关卡与存档的运行时边界，消除不受校验的字符串强制转换。
4. 为本地存档增加版本、校验、旧键兼容迁移与清除进度入口。
5. 为无尽模式限制未使用场景物数量，并将感染体局部排斥从全量两层遍历改为邻近查询。

### 2. 核心战斗机制

1. 在配置中声明敌人的真实行为角色，而不是只由名字或数值暗示。
2. 实现带前摇的远程投射物、冲刺/位移和 Boss 范围技能；所有攻击都有可读预警、冷却和恢复窗口。
3. 为两个 Boss 配置独立机制：坦克 Boss 的冲击/震荡区域，以及爆破 Boss 的目标区域轰炸或爆炸威胁。
4. 将图鉴文字改为仅描述已实现的行为，避免将数值变体误称为独立机制。

### 3. 场景、角色与反馈

1. 将三关从共享网格改为具有关卡主题的地面、边界、非碰撞细节和交互布点，保持碰撞体与视觉主体一致。
2. 改善高频道具、掉落、武器状态与玩家持枪表现，使四把可用武器在画面和反馈上有可辨识差异。
3. 引入统一音频管理：用户手势解锁、主/音效/音乐音量、战斗和 UI 基础音效、暂停与切场景行为。
4. HUD、暂停与设置页面从真实键位配置生成提示，补齐存档重置入口和必要状态反馈。

### 4. 验证、测试与文档

1. 增加配置完整性与纯逻辑自动化测试，覆盖存档迁移、旋转碰撞边界、波次/敌人引用与关键战斗规则。
2. 补充可重复的运行时冒烟流程，覆盖菜单、三关、无尽、图鉴、设置、死亡与通关链路。
3. 同步 README、总规划与执行记录，删除与当前仓库事实冲突的描述。

## 风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 新行为破坏现有波次难度 | 每个能力配置独立冷却、数量和预警；先限定出现波次和并发。 |
| Arcade Physics 不支持旋转刚体 | 用旋转视觉的 AABB 作为明确近似，并为当前 90 度障碍加入测试。 |
| 新特效、对象和音频增加性能负担 | 高频投射物复用对象池，场景物设上限，音频限频并在暂停时静音。 |
| 旧 localStorage 数据损坏或结构不同 | 读取时校验、归一化、迁移；保留旧键兼容和显式清除入口。 |
| 文案和配置继续漂移 | 图鉴、HUD、掉落和关卡说明优先从真实配置派生，并加入完整性测试。 |
| 无浏览器环境导致误判 | 静态测试只证明逻辑；运行时和截图验收单独记录为待验。 |

## 优化方案

1. 采用空间哈希收敛僵尸局部排斥与邻近检查，只有相邻格对象参与计算。
2. 将短生命周期对象统一纳入对象池或限额管理，避免长局内持续分配。
3. 将敌方能力用配置和事件表达，避免继续在 `Zombie` 中堆叠 ID 判断。
4. 将输入标签、声音设置和存档版本集中在共享模块，避免 HUD、设置与运行时各自维护副本。

## 验证方式

1. `npm run typecheck`。
2. 自动化测试：存档迁移、配置引用、旋转碰撞 AABB、换弹取消、敌人能力条件和无尽对象上限。
3. 浏览器冒烟：主页、武器库、怪物图鉴、设置、三关和无尽模式均可进入，控制台无异常。
4. 试玩：每种特殊敌人至少完成一次预警、执行、躲避/反制；两个 Boss 至少进入并完成一次技能循环；第一关可到失败或结算。
5. 桌面 `1280 x 720` 截图检查：文字无溢出，HUD 不遮挡关键预警，障碍物视觉和碰撞一致。

## 执行结果

### 已实施

1. `WeaponManager` 使用可取消的 `TimerEvent` 和令牌校验；切枪、退出场景或新换弹会使旧回调失效。
2. 旋转障碍物使用旋转矩形 AABB，当前第三关 90 度路障会交换物理宽高。
3. `SaveManager` 增加 `saveVersion`、旧键归一化、键位/音量结构校验、进度重置和全量重置能力。
4. HUD 从真实键位生成道具/暂停提示，显示换弹状态和 Boss 生命；设置页增加音量滑杆和二次确认的进度清除入口。
5. 感染体能力统一为配置化前摇、执行、恢复和冷却：冲刺、远程投射、Boss 震荡和目标区域轰炸均已接线。
6. 新增 `EnemyProjectile`、`EnemyAbilitySystem` 和敌方危险区；投射物可被障碍物阻挡，Boss 范围技能只伤害玩家。
7. 无尽模式使用空间哈希进行局部邻近查询，并将未使用场景物限制为 12 个，达到上限时回收最早对象。
8. 三关和无尽模式使用独立的程序地面、边界与非碰撞细节；道具、掉落和四把可用武器的玩家侧表现已增强。
9. 新增 Web Audio `SoundManager`，接入用户手势解锁、音效限频、主/音效/音乐音量、菜单/战斗氛围和核心战斗/UI 事件。
10. Boot 阶段执行配置完整性校验；图鉴文字已同步实际冲刺、远程和 Boss 机制。
