# 2026-07-30 战场背景恢复与交互物美术替换

## 目标

1. 将战场地面恢复为项目原有的低照度程序化关卡背景，移除当前 Kenney 地面瓦片平铺。
2. 为油桶、面粉桶、地雷、拾取物和双方投射物引入一套新的统一俯视像素资源，替换当前不符合游戏设计的切图。
3. 保持碰撞、伤害、对象池、掉落、关卡坐标、武器逻辑和场景流不变。
4. 保留完整来源、许可证、处理脚本和资源台账，使资源替换可追溯、可复现。

## 视觉主张

战场继续使用原有低饱和、低照度的灾后程序化背景；高频交互物采用统一的正交俯视像素图，轮廓、明暗和功能色明显高于地面，但不使用明亮卡通塑料质感。所有小物件必须在 `1280 x 720` 实机尺寸下能被快速识别。

## 范围

1. `BattlefieldRenderer` 恢复原有四套程序化主题背景。
2. 筛选并归档许可证清晰的新素材包，补齐 `SOURCE.md` 和许可证文件。
3. 调整资源处理脚本，稳定输出以下运行时透明 PNG：
   - 油桶、面粉桶、地雷。
   - 弹药、生命、普通道具、武器、强化包拾取物。
   - 玩家普通弹、爆炸弹、敌方投射物。
4. 更新 `PreloadScene`、环境纹理键、实体纹理选择、显示尺寸和动画反馈。
5. 更新美术资源台账和本执行文档的实施结果。

## 不做项

1. 不调整玩家、感染体和武器主体资源。
2. 不改变关卡障碍物坐标、碰撞体、伤害、掉落概率和移动速度。
3. 不把地面改成新的瓦片地图，不引入地图编辑器或新的运行时依赖。
4. 不删除当前已归档的 Kenney 原始资源；停用后仅从运行时加载链路移除。
5. 不执行 `npm run build`。

## 操作步骤

1. 核对当前背景、预加载、纹理键、处理脚本和实体显示链路。
2. 将 `BattlefieldRenderer` 恢复为原程序化实现，并移除不再使用的地面与装饰纹理加载。
3. 从官方素材页筛选许可明确的候选包，要求正交俯视、透明背景、统一像素密度和足够的物件覆盖率。
4. 下载原始包到 `src/assets/downloaded/`，记录来源、作者、下载链接、许可证和下载日期。
5. 修改处理脚本，只从已归档原始资源生成白名单运行时文件，并校验尺寸、透明通道和非空像素。
6. 在 `EnvironmentAssetManager` 中维护稳定纹理键和按业务类型的精确映射。
7. 调整 `Prop`、`Pickup`、`Bullet`、`EnemyProjectile`，保持原物理与生命周期，仅替换视觉主体和必要的显示尺寸。
8. 更新资源台账，明确 Kenney 环境资源已停用、新资源的接入状态和派生关系。
9. 运行素材处理脚本、测试、类型检查和差异检查；启动开发服务器做浏览器实机验收。

## 实施建议

1. 背景和交互物分层维护：背景继续程序绘制，交互物使用透明位图，避免整套瓦片包绑架当前关卡设计。
2. 优先采用一套主资源包；只有主包确实缺失某类物件时才允许补充来源，并通过统一调色、轮廓和输出画布消除拼贴感。
3. 小型弹体保留程序化辉光或拖尾作为反馈，但位图主体必须真实加载，不能继续用纯圆点冒充资源。
4. 拾取物按准确业务类型映射，不用单一图标覆盖弹药、生命、武器、普通道具和强化包。
5. 处理后文件统一使用透明 PNG、最近邻采样和稳定文件名，运行时不直接引用原始大图或素材表。

## 潜在风险分析

| 风险 | 影响 | 控制方式 |
| --- | --- | --- |
| 候选资源授权不清晰 | 无法合法发布或追溯 | 仅接入官方来源页与明确许可证，原包、来源记录和许可证一并归档 |
| 新资源与人物/武器像素密度不一致 | 战场仍有拼贴感 | 统一输出画布、最近邻缩放、有限色板和实机截图复核 |
| 小型弹体原图缩小后不可读 | 玩家无法判断弹道归属 | 使用不同轮廓与功能色，并保留轻量辉光；在实机尺寸而非源图尺寸验收 |
| 拾取物纹理映射不完整 | 新增掉落显示错误或回退成同一图标 | 按 `DropDef.type` 和已确认字段建立穷尽映射，并覆盖 `enhancement_pack` |
| 视觉尺寸改变碰撞感知 | 看见的物体与命中区域不一致 | 物理半径保持现状，显示尺寸围绕现有半径校准并逐项碰撞检查 |
| 工作区已有并行改动 | 覆盖其他开发内容 | 只对明确文件做局部补丁，不回退无关改动，修改前后检查差异 |

## 优化方案

1. 将资源文件名、纹理键和业务映射集中管理，避免实体内部散落路径和猜测式回退。
2. 处理脚本输出确定性文件，并在每次运行后验证 alpha、包围盒和目标尺寸。
3. 地面纹理停用后从预加载白名单移除，减少无意义的网络请求和显存占用。
4. 后续若交互物继续扩张，再将同源小图合并为 atlas；当前数量优先保持可读和可维护。

7. 确认拾取、命中、爆炸、对象池回收和障碍碰撞行为未改变。
