# 2026-08-12 G4-1/G4-2 战斗信息与结算统计

> 状态：统计链路已实施；G4-1/G4-2 仍有 UI 细项待完成

## 1. 本批目标

把 G1/G2 已存在的即时反馈沉淀成可复核的战斗统计，并让失败页/通关页显示最高连杀、暴击、处决、穿透和环境利用结果。

## 2. 已实施

1. `GameState.stats` 新增 `criticalHits`、`executions`、`pierceHits`、三类环境触发计数和 `weaponUsageMs`。
2. `GameScene` 在唯一命中结算点、场景物统一触发入口和每帧武器状态处累计数据。
3. `GameOverScene` 与 `LevelClearScene` 显示最高连杀、爽感机制计数和环境利用摘要。
4. 原有分层伤害数字、连杀 HUD、Boss 阶段血条和战斗警报保持不变。
