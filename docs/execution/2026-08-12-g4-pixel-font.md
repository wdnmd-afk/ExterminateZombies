# 2026-08-12 G4-5 中文像素字体统一

> 状态：已实施；自动验证通过；浏览器实景验收待环境恢复
>
> 依据：`docs/design/LONG_TERM_OPTIMIZATION_GOALS.md` G4-5 / C-7、`docs/design/ART_BIBLE.md`、`docs/ART_ASSET_REGISTRY.md`
>
> 素材授权：用户已确认可按台账规则下载 OFL 素材；Goal 收口可执行 `npm test` 与 `npm run typecheck`，`npm run build` 仍未授权

## 1. 目标

使用官方方舟像素字体统一游戏的中文与西文 UI 字体语言，消除对 Microsoft YaHei、Impact、Arial Black 和 Consolas 等系统字体的运行时依赖，并保证简体中文不发生缺字回退。

## 2. 范围

1. 从 `TakWolf/ark-pixel-font` 官方发布页下载适合 Web 的比例字体发布包。
2. 归档原始发布包、实际运行时字体、OFL 许可证原文、来源、版本、哈希和下载地址。
3. 在首个 Phaser Text 创建前加载简体中文字体，统一导出 UI 字体栈。
4. 替换 `src/` 内全部 Phaser Text 系统字体声明。
5. 同步 Credits、美术台账、长期 Goal 状态与本执行记录。

不包含字体子集化、修改字体字形、重做 UI 布局、引入第二套展示字体或执行生产构建。

## 3. 操作步骤

1. 核对官方仓库、发布版本、发布资产、字体许可证与语言变体命名。
2. 下载 `12px proportional woff2` 官方包，保留原始 ZIP，从中选取 `zh_cn` 变体用于运行时。
3. 计算 ZIP 与运行时字体 SHA-256，编写 `SOURCE.md`，原样归档 `LICENSE-OFL`。
4. 新增字体常量与启动加载模块；`BootScene` 在创建首个 Phaser Text 和进入 Preload 前等待字体，失败时保留明确的本地兜底栈并输出错误。
5. 将所有场景、实体和系统中的 `fontFamily` 改为统一常量。
6. 在 Credits 中补充字体作者、字体名和许可证，在美术台账中登记实际加载路径和状态。
7. 检查所有运行时中文字符是否包含于字体；检查源码中不再残留旧系统字体声明。
8. 执行全量测试和类型检查；启动开发服务器检查主菜单、设置、图鉴、战斗 HUD 在 1x/2x 渲染下的排版、缺字和控制台错误。

## 4. 实施建议

1. 使用官方推荐的比例模式，避免等宽字体造成中西文混排重心和按钮宽度异常。
2. 选择 12px 基准以覆盖当前 10-88px 的 UI 字号，并让常用 12/24/36/48px 尺寸保持整数倍像素结构。
3. 运行时只加载 `zh_cn` 变体，减少无关地区字形与资源体积；原始 ZIP 保留全部官方文件以便追溯。
4. 字体常量集中维护，不继续在场景内散落字符串。

## 5. 潜在风险

1. 字体宽度变化可能导致现有按钮、HUD、图鉴与设置页文本溢出。
2. Phaser 在字体完成加载前创建 Text 会缓存错误量度，造成首次排版跳动。
3. 字体包可能缺少项目使用的个别符号；只看中文正文不足以证明无回退。
4. 仓库级 GitHub 许可证显示 MIT，但字体本体使用 OFL 1.1；归档错误许可证会造成合规问题。
5. WOFF2 资源增大首屏传输体积，需要记录并在浏览器中确认加载成功。

## 6. 优化方案

1. `BootScene` 使用 `FontFace` 与 `document.fonts` 显式等待字体可用，避免依赖浏览器隐式加载时序。
2. 标题、正文和档案标签共享同一字体文件，通过字号、颜色和描边建立层级，避免额外资源负担。
3. 后续若首屏体积成为瓶颈，可另立 Goal 基于实际运行时字符生成 OFL 合规子集；本次不直接裁剪原始字体。

## 7. 验证方式

1. 静态检查：旧系统字体字符串计数为零；所有 `fontFamily` 均引用统一常量。
2. 字形检查：用字体 cmap 覆盖源码运行时字符串中的中文、拉丁、数字和符号，缺失列表为空或仅包含明确由字体栈处理的非文本符号。
3. 自动验证：`npm test`、`npm run typecheck`。
4. 浏览器验证：字体请求成功、`document.fonts.check` 返回真，主菜单/设置/图鉴/战斗 HUD 在 1280 x 720 的 1x 与 2x 渲染下无缺字、错位、溢出和运行时异常。
5. 不执行 `npm run build`；生产构建状态如实保留为未验证。

## 8. 实际结果

### 8.1 实施偏离

原计划在 `main.ts` 创建 Phaser 实例前等待字体；预读入口后确认这需要顶层 `await` 或把默认导出改为 Promise，而当前生产目标为 `es2020`，会无必要地改变入口契约并增加构建兼容风险。调整为由 `BootScene` 在创建首个 Phaser Text 和进入 Preload 前等待字体：仍保证所有文字对象使用准确字体量度，同时保持现有同步 Phaser 入口不变。

### 8.2 已完成内容

1. 已归档官方 `2026.08.11` 发布包 `original.zip`、`zh_cn` WOFF2、OFL 1.1 原文、`SOURCE.md` 和 `ATTRIBUTION.md`；记录 ZIP、运行时字体和许可证 SHA-256。
2. 新增 `src/ui/fonts.ts`，通过 `FontFace`/`document.fonts` 在 `BootScene` 首个文字对象创建前完成字体加载；加载失败保留浏览器无衬线兜底并输出错误。
3. `src/` 全部 146 个 `fontFamily` 声明统一为 `PIXEL_FONT_FAMILY`；旧 `Microsoft YaHei`、`Impact`、`Arial Black`、`Consolas` 字符串已清零。
4. Credits、README、美术资源台账已登记字体作者、来源、版本、许可证和运行时路径；长期规划 G4-5 已标记完成。
