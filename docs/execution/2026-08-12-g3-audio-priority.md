# 2026-08-12 G3-1 音效优先级混音

> 状态：已实施，V1/V2 通过；V6 主观混音待后续验收

## 1. 目标

建立四级音效优先级，确保玩家受伤与 Boss 预警不会被高密度枪声、命中声和普通反馈淹没。

## 2. 实施

1. `AudioEventDef` 新增可选 `priority`：1 为最高，4 为最低。
2. 玩家受伤、Boss 入场和 Boss 阶段为 1 级；四把切片武器开火为 2 级；未声明事件兼容按 3 级处理；UI 移动/确认明确为 4 级。
3. 当新音效加入活动列表时重新应用音量：高优先级播放期间，低级事件按 0.28/0.50/0.78 三档 duck；同级和更高级保持完整音量。
4. 设置音量变化、Listener 更新和新音效加入均走同一套音量计算，避免恢复音量与优先级状态脱节。

## 3. 验证

- `tests/audio-priority.test.ts`：优先级分层与合法范围。
- `npm test`：收口时 16 个测试文件、153 项用例通过。
- `npm run typecheck`：退出码 0。
- V6 耳机/扬声器实听：尚未完成，不能以自动化替代。

## 4. 剩余风险

当前 duck 依据活动音效事件的最高优先级，不对音乐单独压低；G3-3 Boss BGM 和 G3-4 主观混音验收时再补音乐侧动态范围与多浏览器听感记录。
