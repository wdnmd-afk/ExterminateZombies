# 2026-07-30 全武器测试开放

## 目标

让武器库中的 8 把武器全部进入可操作的测试状态，玩家进入任意关卡或无尽模式时即可通过滚轮循环切换并完成开火、换弹、命中、爆炸和 HUD 验证。

## 范围调整

`docs/execution/2026-07-29-project-remediation.md` 原本将“未经验证地开放全部后备武器”列为不做项。用户现已明确要求先开放全部武器用于测试，因此本任务将四把后备武器改为**测试初始配发**，但不把它们伪装成正式敌人掉落或正式平衡内容。

## 范围

1. 为 AK-47、Barrett M82、RPG-7、M79 增加真实 `WeaponDef`。
2. AK-47 与 Barrett 使用现有弹道、贯穿和弹匣系统。
3. RPG-7 与 M79 增加命中爆炸，并使用独立爆炸弹药类型。
4. 测试局初始拥有全部 8 把武器、满弹匣和足够备用弹药。
5. 武器库将四把后备武器标记为“测试配发”，不再显示“未开放”。
6. 战斗角色改用无枪基础角色条，并把 8 把真实武器贴图挂到玩家手部覆盖层。
7. 补齐武器音效、弹药显示、配置校验和自动化测试。

## 不做项

1. 不把新武器加入正式敌人掉落表。
2. 不将当前数值视为最终平衡。
3. 不新增武器栏 5-8 的直接键位；测试时使用鼠标滚轮遍历全部武器，数字键 1-4 继续选择前四栏。
4. 不制作新的角色持枪逐帧动画；本轮使用现有无枪角色动画与真实武器贴图组合。
5. 不制作正式音频资产。

## 操作步骤

1. 扩展 `AmmoType` 与 `WeaponDef`，支持爆炸弹药和命中爆炸配置。
2. 为四把武器补齐伤害、射速、弹匣、换弹、弹速、散射、贯穿、射程和爆炸参数。
3. 扩展 `Bullet` 生命周期，使爆炸弹在命中敌人、场景物、障碍物或达到射程时只引爆一次。
4. 调整 `GameState` 初始测试配发，自动生成所有武器满弹匣并提供测试备用弹。
5. 更新武器库状态、玩家武器表现、音效和爆炸弹药显示。
6. 将武器裁帧、缩放、手部锚点和枪口距离收口到统一资产管理器。
7. 增加配置与爆炸弹生命周期测试，执行 `npm test`、`npm run typecheck` 和 Vite 模块转换验证。

## 实施建议

1. 爆炸统一复用 `AreaEffectFactory`，保持玩家误伤、场景物连锁和视觉反馈一致。
2. 爆炸弹在直接命中时先结算单体伤害，再结算一次范围伤害；通过消费式接口防止同一弹体重复爆炸。
3. 测试配发使用显式配置开关，后续结束测试时可以一次恢复正式初始武器逻辑。

## 潜在风险

1. RPG/M79 爆炸可能同时触发敌人死亡爆炸和场景物连锁，需防止同一子弹重复结算。
2. 8 把武器共享四个直接栏位，测试者必须通过滚轮访问后四把。
3. 测试备用弹会破坏正常资源经济，必须明确标记为测试模式。
4. 大范围爆炸和高贯穿数值尚未试玩，可能导致 Boss 或波次失去压力。

## 优化方案

1. 把爆炸配置放在 `WeaponDef`，避免在 `GameScene` 按武器 ID 判断。
2. 初始弹匣和拥有列表从 `WEAPONS` 自动生成，新增武器不再需要手工同步多份状态。
3. 图鉴状态从 `availability` 派生，明确区分正式初始、敌人掉落和测试配发。

## 验证方式

1. 配置测试确认 8 项武器档案均能解析到战斗配置。
2. 测试初始状态拥有 8 把武器，所有弹匣为满值，爆炸弹药储备大于 0。
3. 爆炸子弹消费爆炸配置后再次调用不能重复引爆。
4. `npm test` 和 `npm run typecheck` 通过。
5. 浏览器可用时逐把开火、换弹、切换并验证 RPG/M79 的命中、射程爆炸和玩家误伤。
