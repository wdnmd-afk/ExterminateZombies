# 2026-08-20 巨型坦克装甲暴露延伸

> 状态：已实施，待浏览器实景验收
> 关联：`2026-08-07-tank-boss-vertical-slice.md`、`PROJECT_MASTER_PLAN.md`

## 1. 设计目标

现有巨型坦克已经具备震荡、阶段转换和定向冲锋，但恢复窗口只表示“Boss 暂停行动”，
没有把“装甲”主题转化成可操作的伤害机会。本轮将攻击后的恢复期明确为装甲暴露窗口：

1. 第一阶段震荡结束后承受 1.20 倍伤害，提供基础教学。
2. 第二阶段冲锋结束后承受 1.45 倍伤害，奖励成功侧闪后的集中输出。
3. 玩家武器、火焰与场景爆炸物统一使用同一倍率，保留诱导 Boss 引爆油桶的核心反制。
4. 黄色继续表示危险前摇，绿色双环表示可输出的破甲窗口；HUD 同步显示倍率和剩余时间。

## 2. 实施边界

1. 不增加第三种攻击，不改变现有技能距离、前摇、恢复时长或冷却。
2. 不改变其它 Boss；未配置恢复期受伤倍率的能力继续按 1 倍伤害结算。
3. 倍率配置限制在大于 1 且不超过 2，防止误配置跳过 Boss 阶段。
4. 震荡引爆场景物与能力执行发生在同一帧时，破甲倍率必须生效，不能受系统更新顺序影响。

## 3. 验收标准

1. 第一阶段震荡后 HUD 显示 `破甲×1.20`，绿色双环与 720ms 恢复期同步出现。
2. 第二阶段侧闪冲锋后 HUD 显示 `破甲×1.45`，窗口持续 900ms。
3. 同一武器在普通时段和破甲时段的伤害数字比例分别接近 1:1.20、1:1.45。
4. 震荡引爆油桶命中 Boss 时使用 1.20 倍倍率，且连锁仍只触发一次。
5. 未配置倍率的其它 Boss 继续显示普通反击窗口，伤害不变。

## 4. 验证计划

1. V1：配置完整性测试覆盖倍率范围与 tank 两个能力的固定值。
2. V2：TypeScript 类型检查。
3. V3/V4：浏览器定向生成 `tank_boss`，记录普通命中、震荡恢复和冲锋恢复三个时点的 HUD、伤害与控制台状态。
4. V5：第二关完整流程仍需连续试玩；Agent 可验证客观闭环，难度舒适度留给 V6 真人判断。
