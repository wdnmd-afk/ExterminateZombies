## 8. 潜在风险

1. **共享动作布局风险**：从单纹理升级为多纹理序列会影响坦克和爆破者，必须保持现有帧顺序与动画时长不变。
2. **Boss 能力抢占风险**：阶段解锁能力优先检查，技能范围必须互补或依赖独立冷却形成明确交替。
3. **武器软锁风险**：后四把武器若只有掉落没有弹药补给，会成为一次性展示内容。
4. **经济波动风险**：独立随机掉落可能同时产生多个物品，实际弹药和武器获得节奏必须进入完整试玩。
5. **关卡名义完成风险**：配置、主题和简报完整不等于正式场景、美术、平衡和可玩性完成。
6. **验证阻塞风险**：当前没有集成浏览器，Boss、HUD、掉落和关卡只能完成代码实施，无法完成 V3-V5。

## 9. 优化方案

1. 多纹理动作布局完成后，后续 wounded 或分段技能动画可复用同一资源协议。
2. 武器经济验收时记录首获波次、备用弹量、重复掉落和软锁时长，不凭单次通关调整。
3. 十关按第一关垂直切片标准逐关验收，代码配置可以批量完整，正式内容仍按批次放行。
4. 浏览器恢复后优先运行三个哨兵：第一关、第五/第十 Boss 关、无尽模式。

4. 怪物图鉴、资源台账、素材 README、Boss 美术执行记录和配置测试约束已同步。

### 11.2 腐化母体

1. 60% 生命进入“母巢苏醒”，速度提升至 1.08 倍，基础投射冷却与恢复分别缩放为 0.82/0.8。

3. Gargant 5 帧攻击与两张共 16 帧死亡图已接入；多纹理动作协议按源数组顺序连续组帧，实体只读取稳定动作键。
4. 怪物图鉴、资源台账、素材 README、Boss 美术执行记录和配置测试约束已同步。

### 11.3 武器正式经济

1. `unlockAllWeapons` 默认改为 `false`；新局只持有满弹匣、无限备用弹的沙漠之鹰，四类备用弹从 0 开始。

3. 爆炸感染体与肿胀者提供常规爆炸弹，毁灭爆破者与腐化母体提供 Boss 爆炸弹补给，避免 RPG/M79 只有首个弹匣。
4. 武器库删除 `testing` availability，全部开放条目统一显示初始配发或从真实 `ZOMBIES` 掉落表派生的来源与概率。
5. 运行时配置校验与 `weapon-loadout.test.ts` 已改为约束正式武器来源、有限弹药补给和普通/Boss 爆炸弹来源。
