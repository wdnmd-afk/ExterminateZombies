# 2026-08-13 G3-3 Boss 独立 BGM

> 状态：已实施，V0 静态核查完成；V1/V2/浏览器/V6 验证待授权或后续验收。

## 1. 目标

让固定关卡 Boss 波次从普通战斗音乐切到独立 Boss 循环，Boss 死亡与关卡结算后回落到菜单/结算音乐，形成可感知的阶段变化。

## 2. 范围

1. 新增一个 CC0 Boss BGM 原始资源与 SOURCE/LICENSE 记录。
2. 通过 `scripts/process_audio_assets.py` 生成 `src/assets/processed/audio/music/boss.ogg`。
3. 扩展 `MusicMode`、`MUSIC_DEFS` 与 `SoundManager.setMusic` 调用点。
4. 在 `GameScene` 的 Boss 波次公告处切换到 Boss 音乐。
5. 更新 `AUDIO_ASSET_REGISTRY.md` 与长期目标进度。

不在本轮处理：

1. 动态交叉淡入淡出。
2. Boss 死亡专属尾奏。
3. 多 Boss 分曲。
4. G3-4 主观混音与多浏览器解码验收。

## 3. 素材来源

候选资源：OpenGameArt `Trance Boss Battle`

1. 来源页：`https://opengameart.org/content/trance-boss-battle`
2. 作者：MintoDog
3. 文件：`trance_boss_battle_bpm150.ogg`
4. 页面类型：Music
5. 页面许可证：CC0
6. 适用理由：明确标注可循环，风格可作为 Boss 战高压循环；许可证不增加署名义务。

## 4. 操作步骤

1. 下载原始 OGG 到 `src/assets/downloaded/audio/trance-boss-battle/`。
2. 补齐 `SOURCE.md`、`LICENSE-CC0-1.0.txt` 与 SHA-256。
3. 修改处理脚本复制生成 `music/boss.ogg` 并刷新 `SHA256SUMS`。
4. 修改 `src/config/audio.ts`：新增 `bossMusic` asset、`MusicMode = 'menu' | 'battle' | 'boss'`、`MUSIC_DEFS.boss`。
5. 修改 `GameScene.announceWave`：Boss 波次公告时调用 `SoundManager.setMusic('boss')`；普通波次保持 `battle`。
6. 补配置测试，锁定 `MUSIC_DEFS.boss` 存在且不复用普通战斗曲。
7. 同步台账与长期目标文档。

## 5. 实施建议

保持 `SoundManager` 的现有 stop/destroy 切轨语义，不在本轮引入淡入淡出。原因是当前音乐系统已经围绕单一活动 music sound 设计，先完成稳定的模式切换，再在 G3-4 主观听感后决定是否需要淡化切换。

## 6. 潜在风险

1. 新音乐未经过浏览器解码与实听，可能在响度或循环点上不适合，需要 G3-4 复核。
2. Boss 波开始即切音乐，若玩家在普通波与 Boss 波之间停留很短，切换可能显得突兀。
3. 外部下载虽然为 CC0，也必须保留来源页、作者、下载地址、许可证和哈希。

## 7. 验证方式

1. V0：静态核对下载记录、哈希、脚本输出、配置引用和 `GameScene` 切换点。
2. V1/V2 建议命令：`npm test -- tests/audio-priority.test.ts`、`npm run typecheck`。
3. V3/V4：浏览器进入带 Boss 的固定关卡，确认 Boss 波资源已加载、无解码错误、`MUSIC_DEFS.boss` 能切换播放。
4. V6/G3-4：耳机与扬声器实听 Boss 切换、循环点和疲劳度。
