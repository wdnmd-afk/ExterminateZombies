## 1. 目标

把强化卡从“只改变静态数值”推进为“改变开火节奏、命中关系或战术选择”的打法变异，同时保持配置驱动、可叠加、可预览和不污染基础武器配置。

## 2. 范围

本批只迁移 3 张卡，覆盖三种不同的行为类型：

1. MP5 `smg_penetration` → **弹链地狱**：每隔固定击发次数触发额外齐射与伤害倍率。
2. SPAS-12 `shotgun_double_pellets` → **四管齐射**：一次开火形成多组齐射，保留弹匣消耗为一发。
3. M4A1 `rifle_less_spread` → **连锁标记**：命中目标后短时间标记，标记窗口内再次命中获得伤害收益。

本批不做：

- 不迁移剩余 21 张卡。
- 不修改基础武器、敌人、掉率、弹药数量或波次数值。
- 不新增音频资源，不改变存档结构，不把强化写入局外存档。
- 不把未完成 V6 的主观结论伪装成数值平衡通过。

## 4. 实施建议

- `burstCount` 只影响一次触发生成的子弹数量，不改变弹匣消耗，避免把卡牌收益隐藏在弹药经济里。
- `ammoChain` 的击发计数按武器 ID 维护，换枪不丢失该武器的节奏；新局、销毁和重新取池时清零。
- `markOnHit` 的过期时间使用场景绝对时间，并在命中读取时惰性清理，避免新增每帧遍历。
- 卡面为行为字段提供“无 → 每 N 发/多组齐射/标记窗口”等可读差异，不能只依赖长描述。

## 5. 潜在风险

1. 齐射同时创建更多子弹，可能放大高密度场景的对象池和碰撞压力。
2. 弹链触发如果跨换枪保留计数，玩家可能无法理解节奏；HUD 暂不显示计数，需实景观察是否需要反馈。
3. 标记伤害与暴击、穿透和濒死倍率叠加，可能形成高于预期的组合爆发。
4. 卡池迁移会改变已有局内卡出现内容；本批只替换 3 张，剩余卡仍是旧行为，必须在文档和报告中明确混合状态。
5. 本任务按用户要求先于 V6 实施，所有数值只能视为首版候选，不得标记最终平衡。

## 6. 优化方案

- 先用纯函数固定合并规则，再接 Phaser 生命周期；行为字段统一从 `EnhancementManager.resolveWeaponDef` 下发。
- 保留卡 ID 以便旧测试和历史证据可追踪，先改语义与效果，不重建卡池索引。
- 用最小行为字段表达三类变化，避免为每张卡新增独立武器分支。
- 若齐射压力过高，优先调行为字段的触发节奏或组数，不先改基础武器伤害。
