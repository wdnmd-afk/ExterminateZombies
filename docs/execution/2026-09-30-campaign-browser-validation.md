# 三十关战役浏览器实景验证

## 目标与范围

用户明确授权 CDP / Playwright 完成浏览器实景测试。本轮补 V3—V5，不以单测、截图或直接调用内部通关方法替代操作。不承诺代理可代替 V6 真人爽感验收。

## 环境与前置

- 仓库既有 Vite、Node 22、Chrome 已存在；当前未安装独立 Playwright，内置浏览器执行接口未在本轮工具中提供。按 TESTING_RULES 9.3 使用 Chrome CDP，无需新增依赖。
- 开始时 5173/9335/9222 均没有监听。本轮只启动并清理自己的 Vite/Chrome，使用新建 `.debug-campaign-browser-20260930` 资料目录，不读取或修改用户浏览器资料。
- TESTING_FLAGS 保持 `unlockAllWeapons=false`、`enhancementDropChance=null`、`monsterArtReviewWave=false`。不得改生命、伤害、时间倍率、敌人数来通过自然战斗。
- 浏览器先监听异常和网络，再模拟焦点、解除后台节流；点击坐标实时读取画布和相机变换，不写死画布比例。

## 操作步骤与矩阵

1. 启动隔离浏览器，验证真实帧推进、预载、菜单、资源/控制台；如启动再次被环境策略拒绝，保留错误并停止，不绕过。
2. 新存档从主菜单进入整备和首关：真实移动、瞄准射击、换弹/切枪、暂停恢复、阶段奖励和结算。只读场景/诊断探针与画面同时留证。
3. 通过明确标注的关卡选择前置数据，遍历三十关的菜单选择、整备、入场、移动/射击、暂停和返回；验证三个分页及锁定行。前置解锁不能作为逐关自然解锁证据。
4. 在正式参数下对代表关卡进行完整战斗，优先 1/2/3 与后期首领关；记录成功、失败、实际耗时、弹药、击杀、关卡结算和下一关解锁，不静默跳过失败。完整三十关自然通关只在实际做到时记录。
5. 检查无尽与狂潮仍可从菜单进入并正确退出。若发现本轮相关产品缺陷，先定位调用链、修复、跑定向自动化，再重新实景验证，保留失败证据。
6. 截图/只读快照/动作日志/控制台和网络结果归档；释放输入、恢复测试开关、关闭本轮页面与进程，更新本文件和 main-goal。

## 实施建议、风险与优化

- 优先复用既有 CDP 协议和诊断入口，不安装工具、不增加正式测试开关。
- 菜单/战斗截图按真实画布检视；目标位置来自当前场景只读状态，行为由 CDP 键鼠事件触发。
- 自动代理失败不自动归因为游戏难度：区分碰撞/输入/资源缺陷、代理走位不足和环境帧率。不得补血或杀怪来把失败改成成功。
- 三十关全量自然通关可能需一小时以上；先保证逐关场景覆盖，完整流程按真实执行进展列出，不能用前置直达冒充通关。
- 若软件渲染或后台帧率偏低，记录设备与 FPS；不把该环境成绩当目标设备性能结论。

## 验证结果

执行日期 2026-09-30，隔离 Chrome + Vite，未改生命、伤害、弹药或时间倍率；证据目录
`docs/execution/evidence/2026-09-30-campaign-browser/`。首次巡检失败与自然战斗过程见下文小节，以下为回填读数。

| 判据 | 覆盖 | 说明 |
| --- | --- | --- |
| 键盘鼠标移动 `moved` | 30/30 | 每关真实移动后记录坐标变化 |
| 真实射击 `fired` | 30/30 | 真实开火并观察弹匣/弹药变化 |
| 暂停与冻结 `paused` / `frozen` | 30/30 | 暂停后场景与画面冻结 |

巡检同时覆盖菜单三页、锁定行不可选中、最后一页边界与窄视口。**这是 `fixtureOnly` 前置模式**：
关卡由前置解锁提供，只证明三十关均可选择、入场、操作与退出，**不构成逐关自然解锁证据**。
前置开始前记录原解锁 `["level_2","level_3","level_4"]`，两轮巡检及第 5、30 关独立开局结束后
均恢复到该值（`actions.jsonl` 的 `*-fixture` / `*-fixture-restored` 成对出现，共 4 对）；
测试开关全程保持 `unlockAllWeapons=false`、`enhancementDropChance=null`、`monsterArtReviewWave=false`。

### B-01：挂起回主页丢失关卡与页码

三十关巡检首次在第一关返回主页时失败：测试开放全部关卡，实际菜单选中 level_30 而非刚退出的 level_1。截图 `tour-failure.png` 和 `tour-failure.json` 保留。调用链 HUD.leaveToMainMenu → GameScene.suspendToMainMenu → MainMenuScene.init/create；挂起分支未传 selectedLevelId，菜单因此执行默认“最高已解锁”。

调整方案：仅战役挂起时携带真实 levelId，无尽/狂潮不附战役选择；保留 sleep 顺序及继续游戏。新增全部三十关传参和非战役隔离回归，跑类型检查，再以新证据前缀重跑巡检，不覆盖第一次失败。

修正后以 `tour-v2-*` 重跑：**30 关全 PASS，`allPassed: true`**，B-01 未再复现，第一关返回主页选中 `level_1`。修复本身只经代码审阅与新增回归，未单独重跑类型检查或全量测试；重跑读数见上文巡检表。

### 自然战斗过程

首关与第二关分别以 1:15 / 1:22 完成，分别 44 / 49 次击杀并解锁后继关。第三关首次误射近身油桶，诊断确认环境伤害 120 后踩入火区阵亡；该失败保留，不归为加载缺陷。测试代理补充已确认的场景物/火区避险只读探针后，第二次以 2:06、81 次击杀击败首领并解锁第四关；未改生命、伤害、弹药或游戏参数。

本轮小结：沿用上面的现场记录，补充两条逐帧核对。第三关失败样本 `oilBarrelsTriggered: 1`，
受伤序列为 `environment` 120 点（105→1）后 `fire` 15 点（1→0），与「误射油桶后踩火区」一致，
不是加载缺陷。第二关 1:22 取自当轮截图、结算页 `final` 为 1:23，只差取整，不构成冲突。
这是第 1—5 关首次自然战斗样本与第 30 关首次独立开局；完整三十关自然通关、六章的
弹药消耗曲线、后期首领阶段时长与真人爽感仍未验。
