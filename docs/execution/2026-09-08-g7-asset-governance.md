1. 普惠体原文件来自镜像；镜像包的许可证不能替代字体权利人的授权。官方许可无法取得或无法确认覆盖当前文件时，G7-3 不能标成全部收口。
2. 部分旧感染体资源可能仍被预载但不再显示，必须如实区分加载状态与实际消费者，不能仅看当前视觉配置就删去授权记录。
3. 游戏内 Credits 与随源码分发的文档不是同一交付物；发布包仍须保留适用的署名、许可与来源信息，构建产物本轮不验证。
4. 同仓库存在并发开发，台账补丁前复核状态，只修改本批范围；并发资源不纳入基线数量。
5. 元数据与静态引用不能证明图片、音频、字体的实际解码和展示，也不能替代版权法律判断。

## 12. 复核入口

固定基线读取：`git show bc75e37:src/scenes/PreloadScene.ts`、`git show bc75e37:src/config/audio.ts`、`git show bc75e37:src/ui/fonts.ts`。显式图片加载加上 `BATTLEFIELD_BITMAP_THEME_IDS` 中非 `level_2` 的十个主题 × 三层即为图片集合；不要把目录内所有 PNG 都计入。

逐文件字节数与指纹可只读复核（不加载 Phaser，也不运行测试）：

```powershell
Import-Csv -LiteralPath docs/RUNTIME_ASSET_INVENTORY.csv | ForEach-Object {
  $asset = Get-Item -LiteralPath $_.path
  $hash = (Get-FileHash -LiteralPath $_.path -Algorithm SHA256).Hash
  if ($asset.Length -ne [long]$_.bytes -or $hash -ne $_.sha256) {
    throw "资源指纹不一致：$($_.path)"
  }
}
```

官方声明正文快照的 `content` 应与 `source_url` 返回的 `data.content` 对照；不要把本地摘要代替中英文全文。新许可文件的 SHA-256 见字体 `SOURCE.md`，CSV 与两份声明的 LF 属性由 `.gitattributes` 固定。
