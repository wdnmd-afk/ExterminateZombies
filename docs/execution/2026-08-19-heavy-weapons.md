# Heavy Weapons Integration

## Scope

Add three obtainable weapons without increasing the five-slot combat loadout:

- GAU-8 Gatling: 180-round belt, trigger spin-up, highest sustained fire rate.
- Golden M249: stable light machine gun with a golden bonus round every tenth trigger cycle.
- Flamethrower: short-range three-stream fire using fuel and refreshable residual fire zones.

## Assets

The Gatling uses Tiamalt's CC-BY 3.0 minigun barrel source. The Flamethrower uses palette samples from TheJosh's CC0 texture. The Golden M249 is generated from Kenney's existing CC0 `weapon_machine.png` with a project-authored box magazine and gold recolor. All three runtime sprites are reproducibly generated by `scripts/process_heavy_weapon_assets.ps1`.

## Runtime Contract

- `belt` ammo supplies Gatling and Golden M249; adaptive drops grant 40 rounds.
- `fuel` supplies the Flamethrower; adaptive drops grant 25 units.
- Gatling spin-up resets when the trigger is released, the weapon changes, reload starts, or combat freezes.
- Flamethrower projectiles create non-explosive fire zones. Nearby equivalent zones refresh instead of stacking, do not hurt the player, and do not create an ambient loop per projectile.
- Each weapon has three behavioral enhancement cards and a real enemy drop source.
