## 1. 目标

1. 在武器库中维护本局出战编队，最多携带 5 把武器，沙漠之鹰固定占第 1 槽且不可移除。
2. 所有战斗模式读取同一份已保存编队；第一关仍以手枪作为当前武器，但不再丢弃其它已选武器。
3. 宽屏时保持中央 `1280×720` 战场不变，把视口多出的左右空间用于常驻 HUD，并在窗口/全屏变化后同步重排。
4. 侧栏按全量、压缩、回退三档呈现；无侧栏时继续使用战场内 HUD。
5. 新增关卡总进度条、5 槽常驻军械带和手枪锁定标记，并保持暂停、抽卡、切枪、拾取与结算流程正常。

## 2. 范围

### 2.1 包含

1. 编队容量、必带武器和存档归一化规则。
2. 武器库中的已解锁判断、编入/移出交互和 5 槽状态反馈。

5. 第 5 武器槽键位、设置页和数字键切枪。
6. 满编队时的局内武器拾取语义：仍解锁许可，但不突破 5 把上限；有空位时加入本局。
7. HUD 三档布局、常驻军械带、关卡总进度、Boss 标记、强化摘要与中央警报居中。
8. 存档、配置、布局与编队相关测试代码同步更新。

10. 运行中调用 `game.scale.setGameSize()` 更新逻辑画布宽度，并同步摄像机、HUD 档位和瞬时状态。

### 2.2 不包含

1. 商店、武器拖拽排序、局内替换已满编队、临时第 6 槽。
2. 移动端布局、主菜单/图鉴/结算页宽屏侧栏化。
3. 武器伤害、掉率、波次数量或敌人数值调整。

## 3. 已锁定决策

| 项 | 决策 |

## 6. 实施建议

1. 编队合法性只在一个纯函数中处理，存档、武器库和开局状态不得各复制一套判断。
2. `PlayerState.ownedWeapons` 继续作为本局真实武器顺序，HUD 和数字键直接消费该顺序。
3. 武器库只允许已解锁武器进入编队，禁止通过界面绕过军械许可。
4. 手枪由归一化层强制放在第 0 项，不能只依靠 UI 禁用来维持约束。
5. 满编队拾取新武器时必须消费拾取并解锁许可，但不能把第 6 把武器写入本局状态。
6. 侧栏档位只由 `resolveDisplayLayout()` 返回，HUD 不重复计算宽度阈值。
7. 关卡进度继续读取 `waveIndex / getWaveTotal()`，不新增波次事件和逐帧进度接口。

## 7. 潜在风险

| 风险 | 影响 | 控制方式 |
| --- | --- | --- |
| 旧存档没有编队字段 | 开局武器丢失 | v4 迁移使用已解锁许可与原偏好主武器生成最多 5 把默认编队 |
| 移除当前偏好武器 | 主菜单或开局引用编队外武器 | 保存编队时同步修正偏好主武器 |
| 第一关固定奖励遇到满编队 | MP5 无法加入本局 | 已满时只解锁许可并给出明确拾取提示；新存档仍有空位，不影响首次教学 |
| 共享弹药池被多把开局武器消费 | 弹药经济变松或变紧 | 本轮每把武器只配满弹匣，仍仅给当前主武器一个备用弹匣 |
| `weapon5` 增加设置行 | 设置页与音频区重叠 | 压缩键位网格行距并保持固定控件高度 |
| 侧栏 50px 边界过密 | 文本或枪图溢出 | 微型形态使用最小 44px 内容宽度，只保留数值、图标和进度，隐藏说明性文本 |
| HUD 每帧刷新五槽 | 增加少量渲染开销 | 复用固定对象池，不创建临时 Phaser 对象 |

## 8. 优化方案

1. 编队选择使用现有武器档案列表和贴图，不新增场景或资源。
2. 先保证最多 5 把的稳定顺序与完整输入，再考虑拖拽排序。
3. A/B 共用一套对象结构，只通过档位参数控制槽高、详情和刻度，避免维护两份 HUD。
4. C 档保留当前战场内排布，降低对 16:9 主流视口的回归风险。
5. 动态跨档重排统一处理所有场景摄像机、文字分辨率和 HUD 瞬时状态。

### 9.3 实景关键路径

1. 武器库：手枪不可移除、锁定武器不可选择、第五把后拒绝第六把、移除后可补位。
2. 开局：第一关当前武器为手枪；其它模式使用编队内偏好主武器；HUD 顺序与编队一致。
3. 战斗：数字 1-5、滚轮、换弹、空弹、拾取与满编队许可解锁行为一致。
4. HUD：C 档不溢出；B 档五槽常驻；A 档显示刻度和强化名称；Boss 区块隐藏时其它区块不跳动。
5. 无尽模式：只显示当前波次文本，不绘制无意义的总进度条。
6. 动态重排：战斗中连续跨 C/B/A，警报、连杀、暂停和抽卡层级保持；挂起到主页后 resize 不得唤醒战局，继续游戏后使用最新档位。
7. 1920×910：计算结果应为 `sidebarWidth=120` 并进入窄 B 档，左右侧栏核心信息不得为空。
8. 50px 边界：`sidebarWidth=49` 回退 C 档，`sidebarWidth=50` 启用微型 B 档；微型形态不得侵入中央战场。
