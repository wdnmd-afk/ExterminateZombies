## 2. P2 独立完整一局

1. 指定第二关“废车站”为垂直切片，试玩者从正式菜单自行选择角色、编队并完成战斗和结算。未解锁时先自然通过第一关，或使用有可追溯自然进度的独立测试配置；两种前置都要如实记录。
2. 测试开始后观察者不提示路线、技能、道具和战斗解法；不会操作、求助、失败、重新开始均按实际时间记录。接受提示的那局不能记作“独立完成”。
3. 结束后先问“这局最让你记住的是什么？”，不提供候选答案。同一名完成该局的试玩者自行写出至少三个不同记忆点；不能拼接多人的答案凑数。
4. 再回填手感、美术、难度、节奏与音频意见。保存结算截图／经同意的录像或现场观察记录；没有实际参与者签认，不关闭 P2。

## 4. 指定设备生产性能（P5）

负责人先确认真实目标设备与合格标准，不能把模拟 CPU 限速、SwiftShader 或开发版 FPS 当低端设备认证。总规划目标为主流桌面 60 FPS，并观察 50／100／150 活跃敌人；这些负载必须各自记录，受控压力场景不能声称自然到达。

- 记录冷启动、正常战斗、50／100／150 敌负载的持续时间、长帧、峰值内存、截图与错误；同设备对比同一构建，不边构建边测性能。
- `node scripts/cdp-production-benchmark.mjs <新编号> <空闲CDP端口> 30` 是本机正式入口的短局采样工具，页面端口为 CDP+1000；不注入游戏状态。它只收集 rAF／Long Task／CDP 指标，**没有内部 Phaser FPS 或敌人数证明**，不能单靠它关闭压力门槛。
- `requiresScreenshotReview` 为真时必须检查实际进入战斗。用户停留菜单、加载异常或页面不可见的记录不能记作有效战斗性能。
- 尚未指定低端设备，当前只有本机 Chrome 生产包基线；正式目标设备／跨浏览器性能仍开放。
