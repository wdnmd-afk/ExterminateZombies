## 0. 文档定位

### 0.1 目标

把"美术、素材、UI、手感、音效、武器、关卡"七个方向的优化收敛为**一组可验收的长期 Goal**，每个 Goal 都：

1. 基于当前代码与配置的真实状态（不臆造现状）。
2. 只使用开源免费素材（CC0 优先，CC-BY/OGA-BY 需署名可接受，CC-BY-SA/GPL 默认排除）。
3. 遵循现有素材治理规则（SOURCE.md、许可证、哈希、台账、处理脚本）。
4. 与 P2 → P3 → P4 阶段路线对齐，不破坏 P2 白名单冻结。

### 0.2 Goal 编号约定

本文档 Goal 使用 `G-` 前缀（G1 手感、G2 武器、G3 音效、G4 UI、G5 美术素材、G6 关卡、G7 治理），与总纲 `D-` 决策编号、`P` 阶段编号并行。每个 Goal 启动时按 §7.2 标准流程在 `docs/execution/` 建立执行文档。

### 0.3 事实基线快照（2026-08-12）

| 领域 | 当前状态 | 主要缺口 |
| --- | --- | --- |
| 手感 | 有枪口闪光、命中火花、受击闪烁、屏幕震动、拟声词；音效已接线 | 无伤害数字、无连杀、无慢动作、无击退/尸体表现、反馈无分层 |
| 武器 | 8 把武器数据驱动、真实型号贴图、24 张强化卡 | 职责重叠（MP5/M4A1）、无暴击/处决/穿透强反馈、手枪无限弹压制经济 |
| 音效 | 9 套开放授权来源、46 个运行时文件、限频/声像/循环已接线 | 无优先级分层混音、缺暴击/处决/穿透/心跳/连杀专属音、主观混音未验收 |
| UI | 战报式菜单/HUD/图鉴/结算成型 | 无统一组件层、无 Credits 页、无可访问性设置（震动/闪光强度）、无伤害数字层 |
| 美术 | 玩家/感染体/武器/场景物/拾取/弹体均为位图；地面/边界/障碍为程序化绘制 | 无美术圣经、多作者像素密度未归一、正式位图地面缺失、特效为程序图形 |

## 1. G1：手感优化（最高优先级）

> 依据：`FUN_FIRST_DESIGN.md` §1、§5；0.1 秒法则 + S/A/B/C 反馈分层。

### 1.1 目标

让"开火、命中、击杀、暴击、穿透、爆炸、濒死"七类瞬间全部具备分层的视听反馈，玩家不看 HUD 也能感知战斗结果。

### 1.2 任务分解

| # | 任务 | 内容 | 依赖 | 状态 |
| --- | --- | --- | --- | --- |
| G1-1 | 伤害数字系统 | 新建 `DamageNumberManager`：白/黄/红/橙分色、1×/2× 分级、飘字动画、高密度自动降级与并发上限 | 无 | 已完成（2026-08-12） |
| G1-2 | 击杀表现 | 尸体沿弹道飞出（物理体立即回池，残影用独立轻量层 2s 淡出）、血液粒子、击杀音效分组 | 对象池时序梳理 | 已完成（2026-08-12） |
| G1-3 | 连杀计数器 | HUD 右上角 3 秒窗口连杀；×5/×10/×20 播报 + 慢动作钩子 | G1-4 | 已完成（2026-08-12） |
| G1-4 | 慢动作系统 | 统一 `timeScale` 管理入口，A 级 0.2-0.5s、S 级 1-3s，全局 5s 冷却；先梳理 WaveManager/EnemyAbilitySystem/SoundManager 计时依赖 | 无 | 已完成（2026-08-12） |
| G1-5 | 震屏分层 | 现有震动改为 S(10-20px)/A(5-10px)/B(2-3px) 三档，接入可访问性强度设置 | G4-3 | 已完成（2026-08-12） |
| G1-6 | 击退系统 | 通用 knockback 字段（SPAS-12 首发），敌人受击位移与分离力协调 | G2-2 | 已完成（2026-08-12） |
| G1-7 | 濒死机制 | 血量 <20%：边缘红脉冲 + 心跳循环 + 移速 +20% + 伤害 +50% + 击杀回 10 血 | G3-2 心跳音效 | 已完成（2026-08-12，心跳事件临时复用素材） |

> 实施记录：`docs/execution/2026-08-12-g1-combat-feel-p0.md`。P0 四项已通过 `npm test`（13 文件/95 用例）与 `npm run typecheck`；浏览器 V3-V6 实景验收待 G1 全批次完成后申请。

### 1.3 验收标准

1. 每类反馈在 0.1 秒内出现视觉 + 听觉双通道。
2. 150 活跃敌人下伤害数字/粒子不糊屏、不掉帧（自动降级生效）。
3. 慢动作不破坏波次计时、强化冻结与音频生命周期（回归现有 80 用例 + 新增计时测试）。
4. V6 真人试玩能明确说出"最爽的一枪"。
