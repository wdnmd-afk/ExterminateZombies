## 0. 文档定位与核心结论

### 0.1 核心理念

**本游戏最大的核心是"爽"。所有设计决策优先服务爽感，其次才是平衡与策略深度。**

```
爽 = 即时反馈 × 掌控感 × 爆发节奏
```

不是"平衡"，不是"策略"，是**"每一枪都爽，每一波都爽，每一局都爽"**。

### 0.2 与既有决策的关系

1. 本文档不推翻 D-001 至 D-006 已锁定决策，而是在其框架内确立"爽感优先"的体验支柱。
2. `PROJECT_MASTER_PLAN.md` §2.3 的体验支柱（移动与枪感、敌群判断、环境战术、短局递进、统一像素风格）保留，但排序调整为：**枪感反馈第一，其它支柱服务于它**。
3. P2 垂直切片（第二关"废车站"）的验收标准在 §9 基础上追加爽感验收项（见本文 §9）。

### 0.3 当前爽感基线诊断（2026-08-12）

| 爽感类型 | 触发时机 | 当前状态 | 优先级 |
| --- | --- | --- | --- |
| 枪械爽 | 每次开火 | ⚠️ 弱（音效已接线待验收，缺后坐/震动分层） | P0 |
| 命中爽 | 子弹击中 | ⚠️ 中（有火花，不够明显） | P0 |
| 击杀爽 | 敌人死亡 | ⚠️ 弱（无击杀停顿、无尸体飞出） | P0 |
| 爆炸爽 | 大范围伤害 | ✅ 强（油桶连锁已有） | 保持 |
| 穿透爽 | 一枪多杀 | ⚠️ 中（有穿透，反馈不足） | P1 |
| 清屏爽 | 瞬间清空 | ⚠️ 弱（无慢动作、无特效） | P1 |
| 逃生爽 | 濒死反杀 | ❌ 无（无血量警示、无反杀奖励） | P1 |
| 成长爽 | 强化变强感知 | ⚠️ 中（有强化，数值感不强） | P2 |
| 节奏爽 | 憋压后爆发 | ❌ 无（3 分钟匀速，无节奏波动） | P2 |
| 掌控爽 | 完美操作被认可 | ⚠️ 弱（无连杀、无评分、无时刻） | P0 |

结论：**"爆炸爽"已成立，其余 9 项均需系统性补强。P0 客观基线中 3 分钟匀速通关，正是爽感曲线平直的直接证据。**

## 1. 爽感设计三法则

### 法则 1：0.1 秒法则

玩家的操作必须在 0.1 秒内得到视觉 + 听觉双重反馈。

```
开火 → 0.05s 枪口闪光 + 后坐 → 0.08s 枪声 → 0.10s 弹道可见
命中 → 0.02s 命中火花 → 0.05s 命中音效 → 0.08s 敌人受击反应（闪白/后退）
击杀 → 0.00s 击杀音效 → 0.05s 死亡动画 → 0.10s 掉落物出现 → 尸体残留 2s 后淡出
```

### 法则 2：爽感分层

反馈不能全部一样强，必须分级：

| 层级 | 事件 | 反馈强度 |
| --- | --- | --- |
| **S 级** | Boss 击杀、濒死反杀、清屏连锁爆炸 | 慢动作 1-3s + 全屏震动（10-20px）+ 中央大字（80px）+ 1000+ 粒子 |
| **A 级** | 精英击杀、5 连杀、穿透 3+、暴击 | 短慢动作 0.2-0.5s + 中等震动（5-10px）+ 60px 文字 + 200-500 粒子 |
| **B 级** | 普通击杀 | 轻微震动（2-3px）+ 40px 飘字 + 50-100 粒子 |
| **C 级** | 移动、瞄准、换弹 | 低调常规反馈 |

当前问题：**所有击杀都是 B 级，缺少 S/A 级高潮。**

### 法则 3：节奏波动

```
爽感曲线必须是波浪形，不能是直线：

高潮 ↑     ╱╲      ╱╲         ╱╲
      ╲   ╱  ╲    ╱  ╲       ╱  ╲
低谷 ↓  ╲╱    ╲  ╱    ╲     ╱    ╲
       准备  释放 喘息 积压  爆发  Boss

当前曲线：————————（平直的 3 分钟）
```

## 2. 武器爽感设计（切片四把）

### 2.1 设计哲学转变

| 之前的思路 | 爽感驱动的思路 |
| --- | --- |
| 武器要平衡 | **武器要极致** |
| 每把都能用 | **每把都爽到爆** |
| 职责要明确 | **瞬间要高潮** |

原则：**一把武器的价值 = 它专属的爽感瞬间**。职责差异（距离/目标/经济三维矩阵）仍然保留，但其目的从"平衡"转为"让每把枪的爽感瞬间无法被替代"。

### 2.2 沙漠之鹰 —— 单发暴击爽

爽感：每一枪都是"砰！"的重击感，赌博式暴击快感。

```
数值方向（相对当前 config/weapons.ts）：
  damage: 25 → 50           // 大幅提高单发分量
  fireRate: 300 → 450       // 降低射速，强化"每发都重要"
  magazineSize: 12 → 7      // 真实弹匣，强化换弹节奏
  新增 critChance: 0.15     // 15% 暴击率
  新增 critMultiplier: 3.0  // 暴击 3 倍伤害
  infiniteAmmo: 保留        // 永远的保底
```

反馈设计：
1. 暴击时：慢动作 0.2s + "CRITICAL!" 黄色大字 + 特殊音效。
2. 击杀时：尸体沿弹道方向飞出约 100px。
3. 空弹：刺耳"咔哒"声 + 屏幕边缘红色闪烁。

### 2.3 MP5 —— 扫射压制爽

爽感：哒哒哒哒的持续输出快感，子弹雨视觉冲击。

```
数值方向：
  damage: 15 → 18
  fireRate: 70 → 50            // 1200 RPM 极高射速
  magazineSize: 40 → 50
  新增 movementPenalty: 0.3    // 移动时几乎不散射（其它枪明显散射）
```

反馈设计：
1. 连续命中 10 发：屏幕边缘红色脉冲。
2. 持续开火 3 秒：枪管发红特效 + 弹壳喷射粒子。
3. 一个弹匣击杀 5+：播报"压制火力！"。

关键机制——移动射击加成（MP5 核心差异化）：

```ts
// WeaponManager 概念实现
getSpreadModifier(weapon, isMoving) {
  if (!isMoving) return 1.0;
  const penalty = weapon.movementPenalty ?? 1.0; // MP5 = 0.3
  return 2.5 * penalty; // MP5 移动散射 ×0.75，其它枪 ×2.5
}
```

### 2.4 SPAS-12 —— 爆破清场爽

爽感：一枪轰飞一片的暴力美学，瞬间清场统治感。

```
数值方向：
  damage: 18 → 28（单弹丸）
  pellets: 7 → 12
  spread: 14 → 20
  新增 knockback: 150          // 命中击退
  新增 executeThreshold: 0.3   // 敌人低于 30% 血量直接处决
  新增 damageDropoff：0-100px 100% / 100-200px 70% / 200px+ 30%
  换弹改为逐发填装，可开火中断，保留已装填进度
```

反馈设计：
1. 一枪击杀 3+：慢动作 0.3s + "RAMPAGE!" 红色大字。
2. 处决击杀：敌人爆成血雾 + 震屏。
3. 逐发换弹 UI：`[■■□□□□] 2/6` 实时显示，随时可打断开火。

### 2.5 M4A1 —— 穿透连杀爽

爽感：一枪贯穿一排敌人的连杀快感。

```
数值方向：
  damage: 35 → 45
  penetration: 2 → 6           // 大幅提高穿透上限
  bulletSpeed: 1000 → 1500
  新增 chainBonus: 1.2         // 每穿透一个敌人伤害 +20%（越穿越痛）
```

反馈设计：
1. 穿透 2 个：黄色"×2"；穿透 3 个：橙色"×3 PIERCING!"。
2. 穿透 5+：慢动作 + 红色"×5 ULTRA PIERCE!" + 特殊音效。
3. 穿透轨迹：留下 0.5s 金色激光轨迹线。

### 2.6 强化卡：从"数值提升"到"爽感变异"

原则：**玩家看到卡面就应该兴奋，用上之后打法明显不同。** 现有 24 张卡中偏"理性数值"的卡（如纯 `damageFactor`）后续逐步替换为爽感变异卡。切片 12 张卡先不改结构，P2 验收后按以下方向迭代：

```
❌ 无聊：'伤害 +20%'（玩家无感知）

✅ 爽感变异示例：
'手枪：处决者'   —— 对低于 50% 血量敌人伤害翻倍，击杀触发小范围爆炸
'MP5：弹链地狱'  —— 弹匣变 200 发，持续射击 3 秒后过热强制停火
'SPAS：四管齐射' —— 一次扣扳机发射 4 发霰弹（耗 4 弹药），后坐巨大
'M4A1：连锁标记' —— 被穿透的敌人标记 2 秒，标记期间被击杀会爆炸
```

现有卡池中 `shotgun_slug`（独头鹿弹）、`pistol_auto`（连射改造）已属于"改变打法"类，是正确方向的样板。

## 3. 敌人设计：从"数值包"到"爽感燃料"

### 3.1 哲学转变

| 之前的思路 | 爽感驱动的思路 |
| --- | --- |
| 敌人是威胁 | **敌人是爽感燃料** |
| 要有挑战性 | **要让玩家爽到飞起** |
| 避免玩家死亡 | **濒死反杀最爽** |

D-004 的战斗角色定义保留；本节在其上追加"爽感用途"维度。

### 3.2 爽感敌人分类（切片白名单内）

| 类别 | 代表 | 爽感用途 | 设计要点 |
| --- | --- | --- | --- |
| 脆皮群体 | `walker` × 20+ | 数量爆感：体验扫射爽 | 血量低到一枪秒，成群出现，被击杀时飞出去 |
| 爆炸怪 | `bomber` | 连锁爆感：打一个炸一片 | 死亡爆炸可触发油桶/其它 bomber 连锁（注：bomber 当前不在切片白名单，需按 §10 变更门禁评估后加入） |
| 穿透靶 | `tank` × 3 排直线 | 技巧爽感：喂 M4A1 穿透 | 精英会排成直线推进 |
| 濒死杀手 | `runner` × 8 | 压力爽感：制造濒死高光 | 高速冲刺包夹，低血量反杀有额外奖励 |

### 3.3 敌人数量目标

**当前 3 分钟约 50 只 → 目标 10-15 分钟 150-200 只。**

时长靠敌人密度与节奏波动填充，不靠拉长间隔。需要配合无尽已有的空间哈希与对象池，并按 §9 性能门槛验证 50/100/150 活跃敌人帧率。

### 3.4 数量曲线（爽感驱动，第二关适用）

```
第一阶段：数量递增（适应期）
├─ 波次 1：5 只 walker（热身）
├─ 波次 2：10 只 walker（开始爽）
└─ 波次 3：15 只 walker + 少量爆炸源（小高潮）

第二阶段：密度爆炸（爽感高潮）
├─ 波次 4：25 只 walker（扫射爽）
├─ 波次 5：30 只 walker + 爆炸怪（连锁爆炸时刻）
└─ 波次 6：40 只混合（屏幕全是敌人的压迫感）

第三阶段：精英压力（濒死爽）
├─ 波次 7：3 只 tank + 20 只 walker（必须集火）
├─ 波次 8：10 只 runner + 混编（高压混乱 / 濒死时刻）
└─ 波次 9：Boss 前奏波

Boss：终极爽感释放
└─ tank_boss + 周期性小怪（不让玩家在 Boss 战里闲下来）
```

## 4. 时刻设计：第二关"废车站"爽感剧本

**每个关卡必须有 5-7 个玩家会记住的"哦！"时刻，写进关卡配置刻意制造，不靠随机。**

| # | 时刻 | 时间点 | 触发与设计 | 反馈 |
| --- | --- | --- | --- | --- |
| 1 | 开场震撼 | 0:30 | 拿到 MP5 后，15 只 walker 三方向涌入；BGM 加速 + 屏幕边缘警示 | 击杀 10+ 播报 "First Blood!" |
| 2 | 连锁爆炸 | 2:00 | 狭窄车厢通道，爆炸源排成一列 + 两侧油桶；打爆第一个引发全链 | 慢动作 1.5s + 震屏 + "CHAIN EXPLOSION!"，一次爆炸击杀 20+ |
| 3 | 濒死逃生 | 4:30 | 血量 < 20% 时 8 只 runner 包围；屏幕变红 + 心跳声 | 濒死击杀播报 "CLUTCH!"，得分 +200% |
| 4 | 穿透狂潮 | 6:00 | 拿到 M4A1 后 3 只 tank 排直线推进 | 一枪穿 3、金色轨迹 2s、慢动作 + "×3 PIERCE!" |
| 5 | 清屏终结 | 8:00 | 30 只同屏时获得清屏道具（候选新道具，按门禁评估） | 慢动作 2s + 白屏闪光 + "EXTERMINATION!" |
| 6 | Boss 登场 | 10:00 | tank_boss 撞破墙壁入场；怒吼 + 地面震动 + BGM 切换 | Boss 血条 + 阶段提示 |
| 7 | Boss 击杀 | 13:00 | 最后一击进入 3s 死亡慢动作，期间可继续射击 | 全屏震动 + "BOSS DEFEATED!" + 金色特效雨 |

## 5. 反馈系统设计

### 5.1 伤害数字

当前没有伤害数字，玩家不知道打了多少伤害。

| 类型 | 颜色 | 大小 | 附加 |
| --- | --- | --- | --- |
| 普通伤害 | 白色 | 1× | — |
| 暴击 | 黄色 | 2× | — |
| 爆头/处决 | 红色 | 2× | 骷髅图标 |
| 穿透 | 橙色 | 1× | 箭头轨迹 |
| 爆炸 | 红色 | 1× | 爆炸图标 |

### 5.2 连杀计数器

屏幕右上角，3 秒内连续击杀累计：

```
×2 白 → ×5 黄 → ×10 橙 → ×20 红 → ×50 金（发光）

播报（屏幕中央弹窗）：
×5  "Rampage!"
×10 "Unstoppable!"（附 0.5s 慢动作）
×20 "GODLIKE!"（附 1s 慢动作）
清屏 "Extermination!"
```

### 5.3 音效优先级（在现有 SoundManager 限频/并发基础上追加）

| 优先级 | 内容 |
| --- | --- |
| 1（最响） | 玩家受伤/死亡、Boss 技能预警、关键时刻播报 |
| 2（响亮） | 武器开火、爆炸、精英击杀 |
| 3（正常） | 普通击杀、命中、拾取 |
| 4（轻柔） | 移动、换弹、UI |

### 5.4 击杀表现

1. 尸体沿伤害来源方向飞出（速度约 300 px/s）。
2. 血液粒子（约 10 枚，500ms 生命周期）。
3. 尸体残留 2 秒后淡出回池（注意对象池回收时序，不能占用池容量导致刷怪停滞）。

## 6. 爽感经济系统

### 6.1 哲学：资源充足优先于资源稀缺

| 传统设计 | 爽感设计 |
| --- | --- |
| 弹药紧张 → 省着用 | **弹药充足 → 爽快用** |
| 血量稀缺 → 怕死 | **血包频繁 → 激进打** |
| 强化稀有 → 靠运气 | **强化保证 → 人人都爽**（D-002 阶段保证强化已符合） |

### 6.2 弹药经济方向

原则：**永远不让玩家因为"没子弹"而不爽。**

| 弹药 | 上限方向 | 掉落方向 | 意图 |
| --- | --- | --- | --- |
| light（MP5） | 600 | 掉落率约 60% | 鼓励放开扫射 |
| heavy（M4A1） | 300 | 约 40%；精英/Boss 保底 50 发 | 敢用穿透，不攒着 |
| shell（SPAS） | 60 | 约 30% | 关键时刻够用 |
| 手枪 | 无限 | — | 永远的保底 |

### 6.3 濒死机制（血量 < 20%）

1. 屏幕边缘红色脉冲 + 心跳音效。
2. 移动速度 +20%（肾上腺素）。
3. 伤害 +50%（背水一战）。
4. 击杀恢复 10 生命（吸血反杀）。

配套掉落：普通敌人生命掉落约 8%，精英 50%，Boss 阶段转换保底大血包。

濒死成就：低于 10% 血量击杀 5 个 → "CLUTCH!"；1 血通关 → "Death's Door" 记录。

## 8. 潜在风险

| 风险 | 说明 | 对策 |
| --- | --- | --- |
| 反馈噪声失控 | 150+ 敌人 × 伤害数字 × 粒子可能糊屏 | 数字/粒子做并发上限与合批；B 级反馈在高密度时自动降级 |

## 9. 验收标准

### 9.1 P0 通过标准

1. 普通击杀有白色伤害数字；暴击/处决有 2 倍大的彩色数字。
2. 连杀计数器 3 秒窗口累计正确；5/10/20 连杀播报触发。
3. 击杀有尸体飞出 + 血液粒子 + 残留淡出，且对象池无泄漏。

### 9.2 P1 通过标准

4. 手枪暴击可见可听，带 0.2s 慢动作。
5. SPAS-12 处决低血敌人一枪秒 + 震屏；逐发换弹可中断。
6. M4A1 穿透有金色轨迹与计数；穿透 3+ 触发慢动作。
7. MP5 移动射击散射明显小于其它武器。

### 9.3 P2 通过标准

8. 第二关有效战斗时长达到 10-15 分钟，靠敌人数量（150+ 只）而非拉长间隔。
9. 至少 3 个"哦！"时刻可稳定复现（连锁爆炸、濒死逃生、Boss 击杀慢动作）。
10. 150 活跃敌人下无明显长期掉帧（按性能预算实测）。

### 9.4 真人爽感测试（对应 V6）

找 3 个未参与开发的玩家各打 2 局，提问：

1. "哪一枪/哪一刻最爽？" → 必须能说出具体时刻。
2. "哪把枪最爽？" → 必须有明确偏好。
3. "想再玩一局吗？" → 至少 2/3 回答想。

**答不上来或不想再玩 → 爽感失败，继续迭代，不进入内容扩产。**

## 11. 最终原则

1. **不要问"这个功能有没有用"，要问"这个功能爽不爽"。**
2. 玩家不会记住 8 把武器、18 种敌人，但会记住"那一枪穿了 5 个僵尸"的瞬间。
3. 每个瞬间做到极致，比每个系统做到完整更重要。
4. 时长靠密度与节奏填充，永远不靠拖慢与空等。
5. 爽感验收以真人反应为准，自动化只证明机制存在。
