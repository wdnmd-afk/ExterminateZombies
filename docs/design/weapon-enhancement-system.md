# 武器强化系统设计

> 版本：2.0
> 状态：代码已接线，待完整浏览器试玩与数值平衡验收
> 事实来源：`src/config/enhancements.ts`、`src/systems/EnhancementManager.ts`
> 关联：`PROJECT_MASTER_PLAN.md`

## 1. 目标

武器强化系统为单局增加有限随机成长，让玩家根据当前拥有的武器和战况选择强化方向。强化只在当前战局生效，不写入局外存档。

系统必须满足：

1. 强化改变武器职责、操作节奏或弹药表现，而不只是统一增加伤害。
2. 玩家选择前能看到当前值与强化后数值，不需要自行计算倍率。
3. 同一武器的多张强化可以叠加，解析结果不依赖拾取顺序。
4. 抽卡冻结战场时，敌人、投射物、换弹和危险区时序保持一致。
5. 卡池、掉落和数值继续配置驱动，不在场景中散落武器 ID 分支。

## 2. 当前规模

当前实现覆盖全部 8 把武器，共 24 张卡，每把武器 3 张：

1. 沙漠之鹰
2. MP5
3. M4A1
4. SPAS-12
5. AK-47
6. Barrett M82
7. RPG-7
8. M79

每次拾取强化包最多抽取 4 张卡。候选卡只来自玩家当前拥有的武器，并排除本局已经取得的卡。

## 3. 玩法流程

```text
击杀感染体
  -> 按掉落表生成强化包
  -> 玩家拾取
  -> 战场以 cardSelection 原因冻结
  -> 从当前持有武器的未激活卡中随机抽取最多 4 张
  -> 玩家用鼠标或数字键选择 1 张
  -> 强化 ID 写入本局 activeEnhancements
  -> HUD 与 WeaponManager 重新解析有效武器定义
  -> 关闭抽卡场景并恢复战斗时序
```

若当前持有武器的卡已经全部取得，强化包直接消耗并显示“暂无可用增强”，不会打开空白抽卡界面。

## 4. 掉落规则

正式概率以 `src/config/zombies.ts` 为唯一事实来源：

1. 普通感染体：当前为 3%-5%。
2. Boss：当前为 100%。
3. `TESTING_FLAGS.enhancementDropChance` 只有非 `null` 时才覆盖正式概率；产品化状态保持 `null`。

掉落类型使用 `enhancement_pack`。运行时、拾取物外观、怪物图鉴和配置校验都必须显式处理该类型。

## 5. 叠加规则

强化不存在互斥组。同一武器的多张卡可以同时持有，按以下稳定规则合并：

1. 倍率类效果相乘。
2. 加法类效果相加。
3. `setToAuto`、`setPellets`、`setPenetration` 等改造类效果取最强一档。
4. 独头弹锁定弹丸数量后，其它弹丸倍率折算为等效伤害，不能把独头弹重新拆回散弹。
5. 爆炸效果先克隆再修改，禁止污染 `WEAPONS` 中的共享基础配置。
6. 弹丸数、弹匣和穿透最终取合法整数；射速、散射和爆炸半径不得为负。

这些规则保证同一组强化无论按什么顺序取得，都解析为相同武器定义。

## 6. 模块职责

### `config/enhancements.ts`

定义卡片 ID、目标武器、标题、描述和效果。配置校验确保：

1. 卡片 ID 与配置键一致。
2. 目标武器真实存在。
3. 每张卡至少有一个实际效果。
4. 爆炸参数强化只引用具备 `impactEffect` 的武器。

### `systems/EnhancementManager.ts`

负责：

1. 从可用卡池随机抽取最多 4 张。
2. 把本局强化集合解析为有效武器定义。
3. 计算某把武器的已强化层数。
4. 生成卡面“当前值 -> 强化后”差异。

### `systems/GameState.ts`

`player.activeEnhancements` 保存本局已激活的强化 ID。新局初始化为空集合，战局挂起/恢复时保留，结算后丢弃。

### `scenes/GameScene.ts`

负责强化包拾取、冻结原因、启动抽卡场景、接收选择结果和恢复战斗。场景不自行计算强化数值。

### `scenes/CardSelectionScene.ts`

负责四张卡的布局、武器贴图、叠加层数、数值差异、鼠标/数字键选择和结果回传。

### `systems/WeaponManager.ts` 与 `scenes/HUDScene.ts`

开火、换弹、弹匣显示和射击模式均通过 `EnhancementManager.resolveWeaponDef` 读取同一份有效定义，避免玩法和 HUD 显示漂移。

## 8. 风险与约束

1. 乘法叠加可能快速放大火力，正式平衡必须按组合而不是单卡检查。
2. 弹匣强化发生在换弹过程中时，本次换弹仍按开始时的需求量结算，玩家可再次换弹补满新增容量。
3. 全武器测试配发默认关闭，抽卡池只覆盖玩家本局实际获得的武器；定向联调临时开启开关时必须在结果中显式记录。
4. 不把本局强化写入 `SaveManager`，避免形成永久属性成长。
5. 不在卡片场景复制武器数值计算，所有实际效果必须收口到 `EnhancementManager`。

## 9. 验收标准

1. 普通感染体按 3%-5% 配置概率掉落强化包，Boss 必掉。
2. 图鉴正确显示“武器强化包 · 概率”，不出现配置异常。
3. 拾取后战场完全冻结，选择后从原时序继续。
4. 四张卡无重复，只属于当前持有武器，已取得卡不会再次出现。
5. 卡面数值与实际开火、换弹和 HUD 一致。
6. 同一武器多张卡可以叠加，且拾取顺序不改变结果。
7. 抽空卡池后不打开空白场景。
8. 完整试玩后记录掉落频率、选择结果和明显失衡组合。
