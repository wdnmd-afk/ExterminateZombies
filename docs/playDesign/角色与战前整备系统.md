## 1. 目标

为现有单人俯视角波次射击增加首版角色系统与战前整备流程，使玩家在进入固定关卡或无尽模式前完成两项明确决策：

1. 从五名首发角色中选择一名，获得固定的生命、移速、伤害、爆头率与专属被动。
2. 从武器库已经保存的出战编队中选择本局首发武器。
3. 角色与首发武器在战前整备页中集中比较和确认，主菜单不再同时承担详细选择职责。
4. 把现有“武器暴击”统一改造成“角色爆头率 + 武器爆头修正”的爆头系统。
5. 保持现有短局、五武器编队、武器许可、局内强化、濒死反击和关卡教学规则不变。

## 2. 范围

### 2.1 本期包含

1. 五名角色配置表、角色视觉映射和首选角色存档。
2. 主菜单到战前整备页的入口。
3. 战前整备页的角色选择、首发武器选择、返回和确认开战。
4. 角色四项基础属性在战斗中的真实生效。
5. 五个专属被动在战斗中的真实生效。
6. 爆头判定、爆头伤害、爆头反馈与结算统计语义统一。
7. 重开本局沿用刚才的角色与首发武器。

### 2.2 本期不包含

1. 角色解锁、角色等级、角色局外成长和角色专属资源。
2. 主动技能、技能按键、技能冷却和技能特效。
3. 局内换角色或波次间换角色。
4. 完整角色剧情、配音、羁绊和角色任务。
5. 在战前整备页编辑完整五武器编队；编队继续由武器库维护。
6. 药品、医疗包和治疗公式改造。不同最大生命与固定治疗量的平衡风险留给后续药品规划处理。
7. 本阶段的自动化测试、类型检查、构建和浏览器实景验收。

## 3. 已确认设计决策

| 项目 | 决策 |
| --- | --- |
| 首发角色数量 | 5 名，全部初始开放 |
| 角色结构 | 四项基础属性 + 一项专属被动 |
| 基础属性 | 最大生命、移速、伤害倍率、基础爆头率 |
| 主动技能 | 首版不做 |
| 成长 | 属性固定，不做局内或局外成长 |
| 局内换人 | 不允许，开局确认后整局锁定 |
| 命名方式 | 代号 + 职能，不展开首版个人剧情 |
| 选择入口 | 主菜单选择关卡/无尽后进入独立战前整备页 |
| 开放策略 | 五名角色全部可选，保存上次选择 |
| 重开策略 | 重开本局沿用刚才角色与首发武器 |
| 枪支选择 | 从武器库保存的出战编队中选择首发武器 |
| 第一关规则 | 保留教学配发，首发武器固定沙漠之鹰 |

## 4. 五名角色配置

### 4.1 首版数值表

| ID | 代号 | 职能 | 最大生命 | 移速（px/s） | 伤害倍率 | 基础爆头率 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| `watcher` | 守望者 | 均衡生存 | 105 | 120 | 100% | 10% |
| `eagle_eye` | 鹰眼 | 精准射手 | 85 | 112 | 95% | 22% |
| `bastion` | 堡垒 | 重装突破 | 140 | 100 | 95% | 5% |
| `runner` | 疾行者 | 机动游击 | 85 | 145 | 90% | 10% |
| `breacher` | 破阵者 | 高风险火力 | 80 | 115 | 120% | 8% |

数值属于首版平衡初稿。未完成真人试玩前，只能标记为“已配置”，不能标记为“平衡完成”。

### 4.2 专属被动

#### 守望者 — 绝境余生

每局一次，受到致命伤害时保留 1 点生命，并获得 1.5 秒无敌。该效果使玩家进入现有低于 20% 生命的濒死状态，可继续获得现有移速 +20%、伤害 +50% 和击杀回血效果。

#### 鹰眼 — 静态校准

连续 0.6 秒不移动后，爆头率增加 10 个百分点；开始移动时立即失效。最终爆头率仍受 50% 上限约束。

#### 堡垒 — 装甲板

来自感染体接触、感染体投射物和感染体特殊技能的实际伤害降低 15%。环境物、玩家自身爆炸和其它非感染体来源伤害不享受减免。

#### 疾行者 — 行进射击

移动造成的额外散射惩罚降低 50%。只降低“移动额外增加的部分”，不把武器基础散射减半，也不覆盖 MP5 等武器已有的移动适性。

#### 破阵者 — 末段火力

当前弹匣在本次开火前剩余量不高于弹匣容量的 25% 时，本轮玩家来源武器伤害提高 15%。换满弹后自然失效；单发武器装填完成时满足末段条件，因此每次射击可获得该收益。

## 5. 爆头系统

### 5.1 统一语义

现有“暴击”改为“爆头”。爆头是实际命中时的概率事件，不增加敌人头部碰撞区域，不要求玩家瞄准像素角色的头部。

### 5.2 最终概率

```text
最终爆头率 = clamp(
  角色基础爆头率
  + 当前武器爆头率修正
  + 角色被动修正
  + 后续明确登记的局内强化修正,
  0,
  50%
)
```

首版武器修正：

| 武器 | 爆头率修正 | 爆头伤害倍率 |
| --- | ---: | ---: |
| 沙漠之鹰 | +10 个百分点 | 2.5 倍 |
| Barrett M82 | +10 个百分点 | 2.5 倍 |
| MP5 / M4A1 / SPAS-12 / AK-47 | +0 | 2 倍 |
| RPG-7 / M79 | 不可爆头 | 不适用 |

### 5.3 判定边界

1. 在弹丸实际命中感染体时判定，未命中的射击不判定。
2. 霰弹每颗实际命中的弹丸独立判定。
3. 穿透弹命中多个感染体时，每个目标独立判定，不能一颗弹全部爆头或全部不爆头。
4. RPG/M79、武器爆炸、强化爆炸、地雷、油桶、面粉桶、火焰残留和场景连锁不触发爆头。
5. 爆头倍率在角色伤害倍率、局内武器强化和穿透加成之后乘算；处决优先于爆头，已经触发处决时不重复统计爆头。
6. 结算和界面统一显示“爆头”，内部音频资源可继续复用现有强调音效文件。

## 6. 角色伤害边界

角色伤害倍率影响：

1. 枪械直接弹丸伤害。
2. RPG/M79 等枪械自身产生的爆炸伤害。
3. 武器强化产生的附加弹丸、击杀爆炸和其它明确归属于当前武器的伤害。
4. 玩家主动布置的地雷伤害。

角色伤害倍率不影响：

1. 油桶和面粉桶的环境伤害。
2. 环境火焰、粉尘或连锁爆炸伤害。
3. 感染体互相造成的伤害。
4. 处决直接清空剩余生命的结算量。

现有低于 20% 生命时的伤害 +50% 继续独立生效，与角色伤害倍率乘算。

## 7. 完整玩家流程

### 7.1 固定关卡

```text
主菜单选择已解锁关卡
  -> 点击“进入战前整备”
  -> 选择角色
  -> 从当前出战编队选择首发武器
  -> 确认行动
  -> GameScene 使用角色与首发武器创建本局状态
```

第一关进入整备页时仍能选择角色，但首发武器锁定为沙漠之鹰，并明确显示“教学配发”。

### 7.2 无尽模式

```text
主菜单点击“无尽模式”
  -> 战前整备
  -> 选择角色与首发武器
  -> 确认行动
  -> 无尽战斗
```

### 7.3 返回、重开与挂起战局

1. 战前整备按 `Esc` 或点击返回时回到主菜单，不覆盖已挂起战局。
2. 从主菜单开始新行动并在整备页确认后，已有挂起战局才被新局替换。
3. Game Over 的“重开本局”沿用失败局的角色与首发武器。
4. 返回主页后再次开始新行动时，默认选中存档中的上次角色和首发武器。
5. 关卡通关进入下一关前重新进入战前整备，允许重新选择角色和首发武器。

## 8. 战前整备界面

### 8.1 视觉命题

**黑色战术台面、旧纸白信息层、警戒黄操作焦点和血红风险提示，使用大幅真实角色像素素材作为唯一主视觉锚点。**

沿用现有主菜单的战地报告风格与阿里巴巴普惠体，不引入终端绿、渐变、玻璃拟态或新的字体体系。

### 8.2 内容结构

1. 顶部：`PRE-MISSION LOADOUT`、当前关卡/模式、返回按钮。
2. 左侧：五名角色纵向名单，稳定行高，显示代号、职能和选中状态。
3. 中央：选中角色大幅像素形象、代号和一句战场定位。
4. 右侧：四项准确数值、被动名称和被动效果。
5. 底部：当前出战编队的武器横向选择带；每项显示真实武器图、名称、弹匣和定位。
6. 右下：单一主操作“确认行动”。

角色名单是重复选择项，可使用紧凑卡片；其余区域使用分栏、分隔线和信息带，不使用卡片套卡片。

### 8.3 交互命题

1. 角色切换：选中标记在 150–200ms 内横移，角色形象短促淡入并从 96% 缩放到 100%。
2. 数值切换：条形底槽尺寸固定，只更新填充宽度和准确数字，不产生布局跳动。
3. 武器切换：当前武器上浮 2px、黄线点亮；确认按钮只在有效角色和有效首发武器存在时可交互。
4. 支持鼠标点击、数字键 `1–5` 选择角色、左右方向键切换武器、`Enter` 确认和 `Esc` 返回。

### 8.4 首页入口

1. 主菜单主按钮文案改为“进入战前整备”。
2. 现有主菜单首发武器左右切换控件改为只读的“当前预设”摘要，显示上次角色与上次首发武器。
3. 主菜单仍负责关卡选择、继续挂起战局、无尽模式和其它档案入口。
4. 角色与枪支的具体操作只在战前整备页发生，避免同一决策在两个页面出现两套状态。

## 9. 数据与系统边界

### 9.1 配置

新增单一角色配置入口，字段只使用本文已确认名称：

```ts
interface CharacterDef {
  id: CharacterId;
  codename: string;
  role: string;
  summary: string;
  maxHealth: number;
  moveSpeed: number;
  damageMultiplier: number;
  headshotChance: number;
  passive: CharacterPassiveDef;
  textureKey: string;
  accentColor: number;
}
```

### 9.2 存档

新增 `preferredCharacterId`，只保存上次确认的角色。五名角色全部开放，不新增解锁数组。读取时只接受已登记角色 ID，缺失或损坏时回退 `watcher`。

### 9.3 战局状态

`GameSceneData` 显式传入 `characterId` 与 `starterWeaponId`。`createInitialState()` 根据角色配置创建生命、移动、伤害、爆头和被动运行时状态；HUD 和结算只读取本局快照，不反查可能已经变化的存档。

### 9.4 场景职责

| 场景/系统 | 职责 |
| --- | --- |
| `MainMenuScene` | 选择模式/关卡，展示上次预设，进入整备 |
| `PreparationScene` | 选择并保存角色/首发武器，确认开战 |
| `GameScene` | 固化本局角色，统一伤害、爆头和被动判定 |
| `GameState` | 保存本局角色属性与被动运行时状态 |
| `SaveManager` | 归一化并保存上次角色与首发武器 |
| `Player` | 使用角色纹理和最终移动速度，维护受伤无敌窗口 |
| `WeaponManager` | 生成携带角色伤害和爆头参数的弹丸 |
| `HUDScene` | 显示当前角色、被动状态和准确生命值 |
| 结算场景 | 显示角色代号与爆头次数，重开沿用本局选择 |

## 10. 风险与优化方案

| 风险 | 影响 | 优化方案 |
| --- | --- | --- |
| 角色伤害与濒死/强化乘算过高 | 跳过普通敌人和 Boss 阶段 | 首版限制角色伤害 90%–120%，爆头率封顶 50%，试玩后按伤害来源统计调整 |
| 堡垒生命与减伤双重放大 | 生存角色成为无条件最优 | 移速降至 100、伤害 95%、爆头率 5%，药品改革时单独校准治疗收益 |
| 鹰眼站桩奖励难感知 | 玩家不知道被动何时生效 | HUD 显示“校准中/已校准”，准星或角色边缘只做短促黄色确认反馈 |
| 爆头仍按开火预判 | 穿透弹会让多个目标共享结果 | 必须迁移到实际命中点逐目标判定 |
| 战前整备重复主菜单选择 | 状态来源不唯一 | 主菜单改为只读摘要，唯一写入口放在整备页 |
| 第一关可以选高阶武器 | 破坏教学节奏 | 第一关整备页锁定沙漠之鹰，角色仍可自由选择 |
| 已挂起战局被误删 | 玩家只进入整备页就丢进度 | 进入整备不停止 sleeping GameScene，只有确认开新局时替换 |
| 五张角色项挤压信息 | 文字截断和比较困难 | 使用左侧稳定名单 + 单一详情区，不在五张卡中重复完整属性和长被动 |

## 11. 验证方式

本阶段按用户要求不运行测试、类型检查和构建，只执行以下静态验证：

1. 角色 ID 从配置、存档、整备、战局、HUD到结算全链路一致。
2. 主菜单不再直接启动新 `GameScene`，固定关卡和无尽模式都先进入整备。
3. 第一关强制手枪，其余模式只接受当前编队内且已解锁的首发武器。
4. 每个角色四项基础属性和一个被动都有唯一运行时消费点。
5. 爆头在实际命中点判定，霰弹和穿透均逐目标独立。
6. RPG/M79 与所有范围伤害不能进入爆头判定。
7. 重开数据携带原角色和原首发武器，下一关重新进入整备。
8. 所有新增交互区域尺寸稳定、文字有宽度约束，鼠标和键盘入口一致。

后续复核阶段建议依次补：角色规则纯函数测试、存档迁移测试、类型检查、战前整备浏览器实景、五角色定向试玩和完整关卡平衡试玩。

## 12. 完成标准

1. 玩家无法绕过战前整备直接开始一局新游戏。
2. 五名角色均可选择，选择结果可保存、可显示、可进入战斗并真实改变四项属性。
3. 五个角色被动均能在各自条件下生效且不串到其它角色。
4. 首发武器只来自当前合法出战编队，第一关例外规则生效。
5. 爆头率公式、武器修正、倍率、上限和排除来源与本文一致。
6. Game Over 重开沿用原选择，通关下一关重新整备。
7. 执行追踪文档逐步记录实际修改与静态核对结果。

## 14. 角色美术升级补充

战前整备不再使用放大的实机小精灵作为角色主视觉。角色美术拆分为两层：

1. **角色档案立绘**：服务战前选择和角色辨识，使用统一规格的透明矢量立绘，运行时按渲染倍率栅格化，因此不存在放大失真。
2. **战斗实机精灵**：服务碰撞、旋转、枪口锚点和高密度可读性，优先从同一授权素材包选择。

两层素材使用独立纹理 key，允许分别迭代。当前两层同源于 Kenney Topdown Shooter：实机用其 `*_hold.png` 位图，立绘用同包矢量源切出的对应姿态，因此服装主色、轮廓和职能装备天然一致。档案立绘目前仍是俯视角而非半身插画，该取舍与后续替换路径见 `docs/execution/2026-08-18-character-art-upgrade.md`。
